# 新人守护师 · 广告鉴别规则知识库

> 赛题二核心：帮助新人鉴别小红书美妆笔记是「真实种草」还是「品牌广告」

---

## 一、官方标识信号（最直接）

| 信号 | 说明 | 可信度 |
|------|------|--------|
| 笔记显式标注「广告」「赞助」「合作」 | 《互联网广告管理办法》强制要求 | ★★★★★ |
| 带购物链接 + 无广告标注 | 强制标注却未标 = 涉嫌违规 | ★★★★★ |
| 笔记挂商品卡/店铺入口 | 商业化导流行为 | ★★★★ |
| 带话题标签 #广告 #赞助 #品牌合作 | 博主主动标注 | ★★★★ |

## 二、内容话术信号

### 广告高频话术（警惕）
- 「品牌爸爸送的」「收到某品牌邀请」
- 「感谢 XX 品牌的礼盒」「免费收到了」
- 「本期是合作笔记」「本篇为合作内容」
- 「XX 品牌请我来测评」
- 「品牌给的 brief 让我重点说…」
- 「#广告 #赞助 #合作」标签

### 真实种草典型特征
- 有具体使用瑕疵或不足
- 提到个人肤质/肤色的适配场景
- 有前后对比图（非品牌图）
- 会和其他产品做横向对比
- 提到价格/购买渠道/退货经历
- 笔记有更新、补记、后续追评

### 夸大吹嘘信号
| 夸大类型 | 典型话术 |
|----------|----------|
| 绝对化功效 | 「立刻变白」「三天祛斑」「一秒磨皮」「永不脱妆」 |
| 医学宣称 | 「药妆级」「治疗痘印」「医学美肤」「医生推荐」 |
| 成分绑架 | 「含 XX 成分 = 最好」「不含就是垃圾」 |
| 效果保证 | 「用完一定白」「所有人都适合」「闭眼入不踩雷」 |
| 价格误导 | 「平价替代大牌」「不到百元堪比千元」 |

## 四、评论区信号词词典

### 社区黑话鉴别（用户自发识别）

| 评论关键词 | 含义 | 说明 |
|-----------|------|------|
| 广子 / 这是广 / 恰饭了 | 广告 | 小红书社区对广告的俗称 |
| 水军 | 虚假评论 | 品牌方雇的假用户 |
| 托 | 广告托 | 配合博主演戏的评论者 |
| 无广吗？ | 求证实 | 真实用户对笔记存疑 |
| 求链接是广 | 质疑导流 | 质疑评论区求链接的动机 |
| 退广 | 劝退广告 | 让博主别发广告 |
| 已退 / 删广已取关 | 反感广告 | 用户因广告取关 |
| 好假 / 一眼假 | 质疑真实性 | 对内容真实性的怀疑 |
| 智商税 | 产品骗局 | 认为产品不值得购买 |
| 避雷 / 踩雷 | 负面真实体验 | 真正的差评信号 |
| 托别来了 | 反击水军 | 真实用户与水军对抗 |
| 博主收了多少 | 暗示广告交易 | 质疑博主动机 |

### 评论区模式
- **正面一致好评** → 可能有水军
- **有褒有贬** → 真实度高
- **全是表情符号 / 短句** → 低质量评论，可能机器刷
- **用户说「广子」但博主未回应** → 高概率广告

## 五、功效宣称合规红线

参考《化妆品监督管理条例》和小红书社区规范：

### 绝对禁止的宣称
- 医疗效果（治疗、处方、药用、药效）
- 绝对化用语（最好、第一、顶级、100%、永久、立即、神奇）
- 保证性用语（一定有效、无效退款、保证变白）
- 虚构成分（不存在的成分或夸大含量）
- 对比贬低（贬低其他品牌产品）

### 允许但需谨慎的宣称
- 「可能」「因人而异」「对我来说」「个人使用感受」
- 使用真实前后对比照片
- 引用第三方检测报告数据

## 六、鉴别决策流程图

```
拿到一篇美妆笔记
  │
  ├─ 有「广告/赞助」标签？
  │     └─ 是 → 直接判定为商业广告（合规与否另行评估）
  │
  ├─ 有购物链接但无广告标注？
  │     └─ 是 → 涉嫌违规广告
  │
  ├─ 内容话术命中夸大词库？
  │     └─ 是 → 高风险夸大吹嘘
  │
  ├─ 博主画像全为新品/礼盒？
  │     └─ 是 → 高概率品牌 KOL
  │
  ├─ 评论区有「广子/恰饭/托」？
  │     └─ 是 → 社区用户识别的广告信号
  │
  └─ 以上皆无 → 初步判定为真实种草（但仍需持续观察）
```
