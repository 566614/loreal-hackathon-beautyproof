### 活 2 · 审图（检查"做对了没"）

队友A 造假图后，会发截图给你。**你用眼睛看，回一个 ✓ 或 ✗**。

**审什么（照这 4 条问）：**

| # | 检查项 | 怎么判 |
|---|---|---|
| 1 | 篡改是不是**真的看得出来**？ | 如果连你都看不出改在哪，说明改得太隐蔽 → 系统也难检测，重做 |
| 2 | 篡改是不是**太假了**？ | 如果一眼假（边缘明显、色差离谱），说明太容易 → 系统学不到东西，重做 |
| 3 | 登记表里写的"改了哪"，跟图上实际改的地方**对不对得上**？ | 写"改了左下角价格"，图上左下角确实变了 → ✓ |
| 4 | 文件名**有没有按规矩命名**？ | 必须是 `003_fake_p图.jpg` 这种格式，编号不重复 |

**回复格式（就回这个，简单）：**
```
003_fake_p图.jpg  ✓
004_fake_拼接.jpg  ✗ 拼接边缘太明显，一眼假
005_fake_ai生成.jpg  ✓
```

### 活 3 · 写《数据说明书》（证明"我们合规"）

这份文档答辩时要用，回答评委"你们数据哪来的"。

**模板已经填好了，你照着改：**

```
## 我们用了哪些数据

**真图（50 张）**
- 来源：小红书 / 微博 / 抖音 公开的美妆种草笔记
- 采集方式：人工下载
- 用途：仅用于本次比赛的技术验证，不作其他用途
- 合规说明：图片均为公开可见内容，不涉及个人隐私信息；
  如涉及版权问题，比赛结束即删除

**假图（40 张）**
- 由我们自己基于真图加工，或由 AI 工具生成
- 加工工具：醒图 / 美图秀秀 / 即梦
- 每类 10 张：局部P图 / 图片拼接 / AI生成 / 文字篡改
- 每张都人工标注了"改了哪里"，作为判断系统准不准的标准答案

**AI 生成图（10 张）**
- 生成工具：即梦（或其他）
- 说明：这类图全部是 AI 生成，不含任何真人肖像

## 我们没做什么
- 没有使用任何人脸 biometric 识别
- 没有对真人做身份判断
- 没有爬取需登录才能访问的内容
```

> 📱 **你怎么交**：手机上写完发阮，她粘进 `data/README.md` 提交到仓库。
