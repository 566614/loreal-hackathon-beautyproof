# 数据登记表格式（data_list.xlsx）

> 这是「零件规格书」。队友A 照这个表头填 Excel，朋友审图，阮的后端脚本直接读这个表。
> 任何人改格式前，必须先在群里说一声，否则前后对不上。

## 表头（每行一张图）

| 列名 | 含义 | 允许值 | 例子 |
|---|---|---|---|
| file_name | 图片文件名 | 字符串 | 001_real_lipstick.jpg |
| label | 真图还是假图 | 1 = 真图，0 = 假图 | 1 |
| tamper_type | 被改的类型（真图写 none） | none / p图 / 拼接 / ai生成 / 改文字 | p图 |
| tamper_region | 被改的位置（真图写 none） | 文字描述 | 左上角嘴唇区域 |
| source | 图片来源 | 小红书 / 微博 / 抖音 / 自造 | 小红书 |
| note | 备注 | 任意文字 | 磨皮过度 |

## 文件存放位置

- 真图放：`data/raw/`
- 假图放：`data/fake/`
- 登记表：先由队友A 用 Excel 填，再导出成 `data/data_list.csv` 给阮的脚本读

## 本周 MVP 数量目标

- 真图：50 张
- 假图：40 张（4 类各 10 张：p图 / 拼接 / ai生成 / 改文字）

## 命名规则（必须照做，不然脚本读不到）

`编号_真假_类别.jpg`

- 例：`001_real_lipstick.jpg`（第1张，真图，口红）
- 例：`002_fake_p图.jpg`（第2张，假图，P图类）
- 例：`003_fake_拼接.jpg`
- 例：`004_fake_ai生成.jpg`
- 例：`005_fake_改文字.jpg`

> 类别只能是这 5 个词之一：real / p图 / 拼接 / ai生成 / 改文字（真图用 real）。
