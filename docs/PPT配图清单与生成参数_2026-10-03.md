## 二、生成参数

### 2.1 图像生成（ImageGen，text-to-image）

两图同批次生成，共用一套风格约束，保证配色/质感一致。

| 参数 | 取值 |
|---|---|
| `size` | `1536x1024` |
| `quality` | `high` |
| `revise` | `false`（不让模型改写提示词，保证可复现） |
| `output_dir` | `docs/assets/` |
| 水印 | 不传 `footnote`（**无水印**，见 §四） |
| 文字 | 提示词里显式禁止 `no text / no watermark / no logo / no letters` |

原始母版（`PNG`，各约 1.4MB）：

- `docs/assets/Ultra_premium_dark_forensic_pr_2026-10-03T05-29-03.png` → 封面
- `docs/assets/Moody_luxury_macro_still_life__2026-10-03T05-29-04.png` → 结尾

### 2.2 后处理（PIL）

```python
ImageOps.fit(im, (1920, 1080), Image.LANCZOS, centering=(0.5, 0.5))   # 从 1536x1024 裁成 16:9
im.save(p, "JPEG", quality=90, optimize=True, progressive=True)
```

产出：

| 文件 | 尺寸 | 体积 |
|---|---|---|
| `docs/assets/cover_main.jpg` | 1920×1080 | 235 KB |
| `docs/assets/closing_main.jpg` | 1920×1080 | 254 KB |

`ImageOps.fit` 是**等比裁切**（裁上下），不是拉伸——原图 3:2、成品 16:9，centre 保留主体。
成品与页面宽高比完全一致：**1920/1080 = 1.7778 = 13.333/7.5 = 1.7778**，PPT 里满幅铺放零变形。

### 2.3 插入 PPT（`tools/make_defense_pptx.py`）

新增 helper `full_bleed_bg(slide, rel_path, darken, tint)`，调用处只有两行：

```python
full_bleed_bg(s, os.path.join("docs", "assets", "cover_main.jpg"),   darken=6400)  # P1
full_bleed_bg(s, os.path.join("docs", "assets", "closing_main.jpg"), darken=6600)  # P21
```

| 参数 | 含义 |
|---|---|
| `darken` | 遮罩不透明度，范围 `0–100000`；封面 6400＝64%、结尾 6600＝66% |
| `tint` | 遮罩色，取全局深色底 `DARK = #121216` |

```python
pic  = slide.shapes.add_picture(path, 0, 0, SW, SH)   # 满幅铺放
mask = slide.shapes.add_shape(MSO_SHAPE.RECTANGLE, 0, 0, SW, SH)
mask.fill.solid(); mask.fill.fore_color.rgb = tint
srgb.append(a:alpha val=str(darken))                   # 半透明
# z-order：把 pic/mask 插回 spTree 最前，原内容自然压在它们上面
```

**每次重跑脚本都会重新嵌图**，不必手工在 PowerPoint 里贴。

## 三、提示词原文（可直接复制复用）

### 3.1 P1 封面

```
Ultra-premium dark forensic product photography. A frosted glass serum dropper bottle
and one coral-red lipstick standing on a matte charcoal slate surface, dramatic single
rim light from the right, deep navy-black gradient background. Faint cyan and violet
spectral waveform lines and a translucent analysis grid float across the right side like
a microscope HUD, thin concentric scanner rings encircle the bottle, a soft FFT
frequency-spectrum ribbon rises behind it. The left third of the frame stays deep black
and empty for text placement. Cinematic, very high contrast, refined beauty-industry
aesthetic, photorealistic product macro photography blended with subtle
data-visualization overlays. Absolutely no text, no watermark, no logo, no letters
anywhere.
```

**对应到 PPT 的关系**：左三分之一纯黑 = 标题「BeautyProof」和副标题的落位区；
右侧频谱线/扫描环 = 对应页面里"多模态取证台"的视觉化。**图像主体（精华瓶+口红）是美妆品类锚点，
不是装饰**。

### 3.2 P21 结尾

```
Moody luxury macro still life. A single elegant glass cosmetic jar half filled with
pearlescent white cream, soft warm golden rim light, floating dust and light particles,
deep charcoal background fading to pure black. A large translucent circular magnifier lens
in the foreground refracting the jar, thin golden and mint-cyan verification ring lines and
a faint dashed measurement grid surrounding it, like a forensic examination view. Deep
shadow occupies the left side with clean negative space for text. Cinematic depth of
field, macro photography, luxurious beauty editorial feel. Absolutely no text, no
watermark, no logo, no letters anywhere.
```

**对应到 PPT 的关系**：放大镜 = 「经得起追问」；校验环 + 虚线网格 = 取证闭环。
与封面是同一套（暗底 / 单侧轮廓光 / 青-金配色 / 左侧留黑），所以两页并置不跳戏。

### 3.3 两图共用的风格锁（复用时务必带上的 6 条）

1. `deep navy-black gradient background` / `dark charcoal` —— 锁死深色底，与 PPT 的 `#121216` 同系
2. 单侧轮廓光（`dramatic single rim light` / `rim light from the right`）—— 锁死打光方向，两图一致
3. **左侧留黑**（`left third ... empty for text placement`）—— 文字可读性靠这个，别去掉
4. `no text / no watermark / no logo / no letters anywhere`—— 杜绝乱码（见 §四）
5. 一个真实美妆实物 + 一层取证科技元素（频谱/扫描环/放大镜）—— 不拍纯装饰
6. `cinematic, very high contrast`—— 投屏不糊

## 四、已知边界（答辩如果被问，这么说）

1. **无水印、无乱码**：两张图都是纯图形+实物，提示词显式禁止文字，生成器也不会往产品图上打中文字。
   因此不存在字体缺失/乱码风险——这也是**不在图上放任何文字**的原因（图上放字，换台机器就乱码）。
2. **分辨率**：素材原生 1536×1024，16:9 裁切后等效 1536×864；PPT 满幅 13.333 英寸 ≈ 1920 px，
   即约 **1.25× 上采样**。1080p 投屏完全够，4K 投屏会略软。
   若要 4K 投屏，把 `ImageOps.fit` 的目标改成 `(3840, 2160)` 做二次放大即可（会更软），
   或者改用"图放右半幅"的版式（等效 792 px，反而 downsample）。
3. **中间 19 页仍无图**：这是刻意的，不是漏做。见 §一。
4. **本机没有 LibreOffice**，无法把 .pptx 渲染成 PNG 做像素级目视校验，
   上述结论全部来自程序化校验（z-order 顺序、shape 坐标、alpha 值、文案比对），**目视确认需要你在 WPS/PowerPoint 里打开扫一眼**。
5. **图是生成图不是实拍**：评委若追问素材来源，答"AI 生成的概念示意图，用于封面视觉锚点，
   项目所有技术结论均由 `results/*.json` 可复现数字支撑，示意图不承担任何数据证明"。

## 五、想微调？改这几个数就够

| 想要的效果 | 改哪里 |
|---|---|
| 图太暗 / 看不清图 | `full_bleed_bg(..., darken=)` 调小（封面 64% → 50%） |
| 图太抢眼文字不清晰 | `darken=` 调大（→ 78%） |
| 换配色（比如偏玫瑰金） | 改 `tint=`，或改提示词里的 `navy-black` → `deep plum` / `warm rose` |
| 换主体（口红 → 粉饼 / 香水） | 提示词里把 `coral-red lipstick` 换成 `pressed powder compact` / `glass perfume bottle`，其余照抄 |
| 完全重生成一张 | 提示词 §3.3 的 6 条风格锁 + §3.1/3.2 正文，参数 `size=1536x1024 quality=high revise=false` |
| 给中间页也加图 | 需要先压窄该页文字/表格宽度腾出空间，别直接往表格上盖 |

## 六、复现命令

```bash
# 1) 生成（ImageGen，2 张，约 10–20 积分）→ docs/assets/*.png
# 2) 裁 16:9 + 压 JPEG
python -c "from PIL import Image,ImageOps; \
from pathlib import Path; a=Path('docs/assets'); \
src1=list(a.glob('Ultra_premium*.png'))[0]; src2=list(a.glob('Moody_luxury*.png'))[0]; \
[ImageOps.fit(Image.open(x).convert('RGB'),(1920,1080),Image.LANCZOS).save(a/y,'JPEG',quality=90) \
 for x,y in [(src1,'cover_main.jpg'),(src2,'closing_main.jpg')]]"

# 3) 重新生成 PPT（图自动嵌入）
python tools/make_defense_pptx.py
```
