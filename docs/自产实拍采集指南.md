# 自产实拍采集指南（赛题2 合规 · 最优选）

> 目的：你和队友拍**自己拥有的**欧莱雅产品 / 真实美妆照，作为「未修图原始标准参考图」扩充 REAL 训练类。
> 这是技术上最优、合规上零风险的来源（我们的真实美妆照误报根因就是缺真实分布）。
> 拍完按本指南落到 `data/xhs_real_unlabeled/`，再跑 `python tools/pseudo_label.py` 自动伪标注进训练池。

---

## 一、拍什么（覆盖多品类 + 多条件）

| 品类 | 拍法 |
|------|------|
| 口红 / 唇釉 | 多个色号：①瓶身平拍 ②上嘴实拍（自然光） |
| 粉底液 / 气垫 | ①瓶身 ②手背试色 |
| 眼影盘 | ①盘体 ②上眼实拍 |
| 护肤精华 / 面霜 | ①瓶身 ②质地特写 |
| 场景变量 | 不同光照（窗边/室内灯）、不同手机直出、戴/不戴妆 |

## 二、怎么拍（关键：证明「未修图」）

1. **手机原相机直出**，关美颜/滤镜/自动美化；不要用修图 App 二次处理。
2. **保留原始文件（别导出压缩版）**，让 EXIF 里的拍摄时间/设备留在图上——这是「未修图原始图」的可核查证据。
3. 光线均匀、别过曝；背景干净即可，不要求棚拍。
4. 每人拍 **10~30 张** 最好（量上去，真实分布才覆盖得全）。

## 三、落盘与命名

- 把原图直接丢进：`data/xhs_real_unlabeled/`（目录不存在就新建）。
- 文件名随意（中文也行），例如 `口红_01.jpg`、`粉底_小李_02.png`。
- 不用写标注——`pseudo_label.py` 会用已上线模型自动判：高置信真实(ai_prob≤0.25)才收进 `data/real_extra/`；
  高置信 AI 会排除并提示你核实；模糊带跳过。

## 四、跑伪标注（自动）

```bash
# 在仓库根目录，用 venv
python tools/pseudo_label.py
# 产出 data/real_extra/（伪标注真实图）+ results/pseudo_label_real.json（每张图处置清单）
# 然后训练 v4：
python tools/train_aigen_v4.py
```

## 五、标注模板（如需手工登记到 manifest）

每张图在 `results/standard_images_manifest.json` 的条目字段：
`file / source(拍摄者名) / license(team-self-produced) / is_retouched(false) / purpose(REAL训练) / in_training / risk(low) / note`。

> 铁律：**只拍自己拥有的产品 / 自己拍的真实照**。别人的图、网图一律不进——那是第三方版权，踩赛题红线。
