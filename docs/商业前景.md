# BeautyProof 商业前景一页纸

> 赛道：L'Oréal 黑客松「信任与真实性」｜ 美妆图篡改取证工具（AI 生成图检测 + 局部 PS 篡改定位）
> 日期：2026-09-25 ｜ 一句话定位：**把"鉴伪"做成"可解释取证"，而非黑盒打分。**

---

## 一、核心差异化（为什么是生意，而不只是算法）

通用 AIGC 检测器在中文美妆域集体失效（本团队实测误报 66% → 本域微调 v3 后跨生成器召回 100%）。BeautyProof 的壁垒不在"某个模型更准"，而在**证据链可解释**：6 个工具（hash / C2PA / ELA / OCR / AIGC / TruFor）+ 文案/跨模态交叉验证共享统一证据格式 `{tool, observed, cannot_prove, evidence[]}`，由规则引擎给出四档结论（`high_risk / suspicious / credible / inconclusive`），再叠加 LLM「人话解读」与多 Agent 圆桌交叉复核。

**商业含义**：品牌方、平台、监管与司法机构买的不是"一张图 0.93 分"，而是**可追溯、可审计、可上法庭的证据链**。这是黑盒竞品给不了的，也是 B 端 / G 端付费意愿最高的部分。

## 二、付费方（Who Pays）—— 分三层

| 层级 | 客户 | 付费动机 | 典型场景 |
|---|---|---|---|
| **B 端 · 品牌方** | 欧莱雅及美妆集团、国货品牌 | 广告合规、品牌素材确权、打击仿冒与虚假种草 | 新品上线前素材审核、代言/达人图自证清白 |
| **B 端 · 服务机构** | MCN / 达人 / 第三方鉴定与维权机构 | 自证清白、出具可采信鉴定报告 | 维权取证、合作方资质核验 |
| **平台端** | 电商 / 内容平台（小红书、抖音、天猫） | 内容治理 KPI、虚假种草/假测评治理 | 美妆内容审核前置、举报工单复核 |
| **G 端 · 监管** | 市场监管、药监、消协 | 虚假宣传治理、消费者保护 | 违法广告抽查、行业监测 |

## 三、市场规模（Market Size）—— 诚实区间，标注来源

**TAM（广义可寻址）｜中国 AIGC 检测 / 内容鉴伪市场**
- 国内深伪检测市场 2025 年约 **43.8 亿元**，预计 2026 年 **63.4 亿元**（同比 +36.2%）—— 中国信通院 + 工信部口径（雪球 2026 转引）。
- 更宽的「中国 AIGC 内容检测（文本+图像+视频）」2025 年约 **45 亿元**，全球约 19–29 亿美元，CAGR 30%+ —— IIM《AI 生成内容检测市场调查 2026》。
- → 取 TAM ≈ **45 亿元/年（2025 中国）**，随监管强制标识持续扩容。

**SAM（可服务｜美妆垂域营销内容审核 + 打假）**
- 2025 年中国化妆品全渠道交易额 **1.10 万亿元**（中国香妆协会，同比 +2.83%），线上占 **65.36%（≈7218 亿元）**——海量 KOL 种草图文/短视频即鉴伪对象。
- 按品牌「内容安全 + 打假 + 合规审核」支出占营销额 **0.1%–0.3%** 估算：1.1 万亿 × 0.2% ≈ **22 亿元/年**（仅美妆垂域）。

**SOM（可获取｜3 年）**
- 以欧莱雅及头部美妆集团为锚点，按 API / 订阅切入，目标 3 年内夺取垂域 **5%–10%** → ≈ **1–2 亿元/年**。

> 说明：TAM 取第三方机构公开口径（非自估大盘）；SAM 逻辑为"营销额 × 保守费率"，不夸大。

## 四、落地路径（Landing Path）—— 里程碑 + 所需资源

- **短期（0–6 月）· 品牌内审插件 / API**
  - 动作：以欧莱雅为标杆客户做 pilot，将取证能力包装为「素材上线前审核插件 / 私有化 API」。
  - 资源（已具备）：v3 本域模型、Flask 取证台（端口 5000）、离线自包含 demo、线上 demo；**待补**：产品化封装、SLA 与计费后台。
- **中期（6–18 月）· 平台内容审核接入**
  - 动作：与电商 / 内容平台对接美妆内容审核 API，治理虚假种草与假测评。
  - 资源：高并发服务化、模型持续训练（补齐 MJ / SD / Flux 跨生成器真图，当前 v3 held-out 召回已 100% 但仅覆盖 ImageGen 风格）。
- **长期（18–36 月）· 行业标准 / C2PA 生态协同**
  - 动作：推动美妆内容「可信凭证」，与 C2PA / 内容溯源标准对齐，成为行业信任基础设施。
  - 资源：行业联盟、监管合作（G 端）、跨平台互认。

## 五、商业模式（How We Make Money）

1. **API 按调用量计费**：单张图取证 / 批量审核，按次或包月调用套餐（适合平台、MCN）。
2. **企业版订阅**：品牌内审平台 / 插件，年费制含私有化部署与模型更新（适合品牌方）。
3. **鉴定报告服务**：出具带完整证据链、可归档转发的 PDF 鉴定报告，按份收费（适合维权机构、监管抽查、司法取证）。

## 六、与欧莱雅战略契合点

- **守护品牌信任资产**：欧莱雅连续居中国美妆市占率第一（2025 约 14.5%，Euromonitor），消费者信任是其核心资产；BeautyProof 直接防御「AI 种草图 / 虚假测评」对信任的侵蚀。
- **打击虚假测评、保护消费者权益**：契合 L'Oréal 可持续与消费者保护基调，且欧莱雅自身大量使用 AIGC 营销，也需「自证清白」的工具——**既是防守盾，也是自检镜**。
- **可解释 = 可合规**：四档结论 + 证据链天然满足广告法 / 化妆品监管对「可举证、可追责」的要求，便于内部风控与监管报送。
