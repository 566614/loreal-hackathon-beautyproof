# 标准图片采集与合规清单（赛题2 · 欧莱雅产品/美妆参考图）

> 目标：在「当前可用图片数量不足」的前提下，扩充一套**来源合法、不违反赛事规范**的标准参考图，
> 并整理出**标注用途**的图片清单。
> 本文件是采集的合规边界 + 协议 + 清单 schema；实际图片清单见 `results/standard_images_manifest.json`。

---

## 一、一句话结论

**不能爬品牌/电商站的欧莱雅产品图**（版权归欧莱雅，ToS 明文禁止商用，商业奖金场景下风险极高）。
合规扩充只有两条路，且都要求「逐张可核查来源 + 许可」：

1. **自产实拍（首选）**：你和队友拍自己拥有的欧莱雅产品 / 真实美妆照，零授权问题、最合规，
   且天然就是「未修图原始标准参考图」——技术上也最优（我们的误报根因正是缺真实分布）。
2. **CC 合规图库（次选/补充）**：仅从 Wikimedia Commons、CC0 公域源（Pixabay/Smithsonian/Met 等）
   拉取**逐张核验过许可**的图，且只收 **CC0 / CC-BY（非 SA、非 NC）**；**排除 CC-BY-SA（传染）与 CC-BY-NC（非商用）**。

## 二、为什么「爬全网品牌图」不行（已查证，带证据）

- 欧莱雅美国官网 ToS：「The Proprietary Material is owned or controlled by L'Oréal... you may not...
  use, publish, reproduce, display... for any purpose or by any means, without our express prior written permission」，
  且「may not be used for commercial purposes」。
- 欧莱雅马来西亚/中国官网 ToS 同义：网站图像版权归欧莱雅，未经书面许可不得复制/展示/衍生，不得商用。
- 赛题2（天池 532496）规则：参赛方案「不得侵犯第三方知识产权」、数据来源需「合法合规」。
  → 爬取的品牌产品图无授权即侵权，直接违反这两条；20 万奖金属商业场景，比 GenImage（CC BY-NC-SA 非商用）
  风险更高——GenImage 我们都已排除，品牌图更不能进。

## 三、赛题2 合规边界（采集视角）

| 来源 | 是否合规 | 理由 |
|------|----------|------|
| 自产实拍（团队拥有的产品 / 真实美妆照） | ✅ 首选 | 自有内容，无授权问题；天然未修图 |
| Wikimedia Commons **CC0 / CC-BY(非SA,非NC)**，逐张核验+署名 | ✅ 允许 | 许可明确允许商用；需 attribution |
| 公域源（Smithsonian/Met/Pixabay CC0） | ✅ 允许 | CC0，免署名可商用 |
| Wikimedia Commons **CC-BY-SA** | ❌ 排除 | 衍生需同协议开源，与专有提交冲突 |
| 任何 **CC-BY-NC / NonCommercial** | ❌ 排除 | 非商用，商业奖金场景不符（同 GenImage） |
| 欧莱雅官网 / 电商站（天猫、京东、官网商城）产品图 | ❌ 排除 | ToS 禁止复制/商用，侵权风险 |
| 小红书 / 微博 / 抖音等社媒美妆图（未获授权） | ⚠️ 仅限「owner 自己提供」 | 他人 UGC 版权归原作者；只有老板/队友自己发或已获授权的才作「团队自产」用 |
| GenImage / COCO / ImageNet(训练集) / 任何第三方训练库 | ❌ 排除 | 赛题红线（见 `docs/训练数据来源清单.md`） |

> 铁律：**每张进库图都必须能在清单里查到「来源 URL / 拍摄者 + 许可类型」**，查不到的一律不进。

## 四、采集协议（落地步骤）

1. **建目录**：
   - `data/xhs_real_unlabeled/`：团队自产/提供的真实美妆图（未标注）→ 走 `tools/pseudo_label.py` 伪标注进 REAL 池。
   - `data/real/`：已确认的自产真实参考图（直接进 REAL 训练）。
   - `data/cc_verified/`：CC 合规图（每张配 `<name>_license.txt` 记来源 URL + 许可 + 作者）。
2. **每张图登记**：落到 `results/standard_images_manifest.json`（schema 见 §五）。
3. **进训练前复核**：`pipeline`/训练脚本只读 `data/` 自产子目录；`data/cc_verified/` 需先经伪标注或人工确认用途。
4. **署名**：CC-BY 图在 manifest 与（若对外展示）报告里保留作者+许可+来源链接。

```json
  "file": "图片文件名",
  "source": "来源（自拍=拍摄者名 / CC=Wikimedia Commons URL / 官网=已获书面授权）",
  "license": "team-self-produced | CC0 | CC-BY(非SA,非NC) | loreal-written-permission",
  "is_retouched": "false(原始未修图) | unknown | true",
  "purpose": "AI训练 | REAL训练 | 跨生成器held-out | 产品参考 | 演示样例",
  "in_training": true/false,
  "risk": "low | medium | high",
  "note": "补充说明"
}
```

## 七、待采集清单（模板，执行前需确认路线）

**自产实拍心愿单**（老板/队友拍自己拥有的欧莱雅产品，原图不修图）：
- 口红/唇釉（多个色号，平拍 + 上嘴实拍）
- 粉底液/气垫（瓶身 + 手背试色）
- 眼影盘（盘体 + 上眼实拍）
- 护肤精华/面霜（瓶身 + 质地）
- 不同光照/不同手机直出（保留 EXIF，证明未修图）

**CC 合规心愿单**（仅 CC0 / CC-BY 非SA非NC，逐张核验+署名，落 `data/cc_verified/`）：
- Wikimedia Commons 类目 `Category:L'Oréal` 下逐张核验许可的产品/场景图
- Pixabay / Smithsonian / Met 中标注 CC0 的美妆相关图（按需）

> 注意：CC 图多为品牌活动/陈列照，**少有「未修图原始产品标准参考图」**；对降低我们「真实美妆照误报」
> 的帮助有限。技术主线仍应放在**自产实拍**上。
