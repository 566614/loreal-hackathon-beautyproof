## 〇、这轮升级的起点：对标检索发现了什么

先做了网络检索对标（同类优秀作品 + 公开 benchmark + 评审偏好），四条结论直接决定了本轮改什么：

| # | 对标发现 | 对我们的意义 | 本轮动作 |
|---|---|---|---|
| 1 | **ELA 对整图 AI 生成基本无效** —— 它查的是"原图 vs 二次编辑"的压缩历史差异，而 AI 从零生成的图没有编辑区、压缩场均匀；且截图/平台重压场景误报文献报告高达 96.8% | 我们此前把 ELA 当成 AI 生成判据之一，是**硬伤** | 新增频域工具替代其位置；ELA 降级为"局部编辑定位器"（P1-4） |

## 一、量化亮点（4 个，全部可复现）

### 亮点 1 · 双检测器级联：自动下架零误伤不变，AI 捕获率 +5.3pt

**为什么做**：本域微调的 AIGC 模型弱在**跨生成器/换风格就掉**；频域弱在**重压/强锐化真实图会误报**。
两者失效模式不同，级联用一条的长处补另一条的短处。

| 配置 | AI 捕获率（≥可疑） | 自动下架误伤（红线） |
|---|---|---|
| 只用 AIGC 模型 | 34/38 = 89.5% | **0 / 20** |
| 只用频域工具 | 34/38 = 89.5% | **0 / 20** |
| **两级联（生产配置）** | **36/38 = 94.7%** | **0 / 20** |

频域工具单独在冻结 TEST 段：**AUC = 0.97**，AI 召回 85% / 真实图误报 0/10。
判罚规则（与项目原有灰带设计一脉相承）：
- 自动下架 = AIGC ≥ 0.99 **或** (AIGC ≥ 0.9 **且** 频域 ≥ 0.8) —— **只有两条独立证据一致才动手**
- 转人工 = AIGC ≥ 0.9 **或** 频域 ≥ 0.6 **或** (AIGC 弃权区但频域强) ← 级联在这一条捞回 2 张

> 复现：`python tools/spectral_calib.py --refit && python tools/cascade_eval.py`
> 产物：`results/spectral_calib.json`、`results/spectral_eval.json`、`results/cascade_eval.json`

### 亮点 2 · 工具消融表：证明"多工具编排"是架构贡献

对标 ForenAgent 的消融结构，**真嵌套**（每层严格包含上一层）：

**表A 纵向消融（生成轴，冻结 38 AI / 20 真实）**

| 层 | 工具 | AI 捕获 | 自动下架 | 真实误伤 |
|---|---|---|---|---|
| T0 | 仅文件指纹 + 内容凭证 | 0/38 = 0.0% | 0 | 0/20 |
| T1 | +ELA（篡改轴） | 35/38 = 92.1% | 0 | 0/20 |
| T2 | +AIGC 模型（单条生成轴） | 37/38 = 97.4% | 33 | 0/20 |
| T3 | **+频域（两轴合并＝级联）** | **38/38 = 100%** | 34 | **0/20** |

**表B 横向互补（篡改轴，受控样本）** —— 这是"三轴互补"而非"工具堆料"的证据：

| 样本 | ELA | 频域 | AIGC | TruFor |
|---|---|---|---|---|
| 真实 clean_01 | 1.685 | 0.148 | 0.000 | 0.350 |
| 真实 clean_02 | 0.710 | 0.150 | 0.000 | 0.411 |
| 复制粘贴篡改 | 3.905 | 0.148 | 0.000 | **0.995** |
| 拼接篡改 | 4.336 | 0.206 | 0.000 | **1.000** |
| 改文字篡改 | 3.935 | 0.171 | 0.000 | **0.595** |

**结论**：频域与 AIGC 对局部篡改**完全无反应**（0.15 / 0.000）；ELA 与 TruFor 对整图 AI 生成无反应。
三条轴各自失效、互相补位 —— 这是我们真正的架构论点，比"我用了 7 个工具"有力得多。

> 复现：`python tools/ablation_eval.py` → `results/ablation_eval.json`

### 亮点 4 · 合规法条引擎（落地与行业价值）

把"命中敏感词"升级成法务能直接用的清单：**违的是第几条 + 会罚多少钱 + 真实案例**。

- 法条知识库 6 类：《化妆品监督管理条例》第 16/22/37 条、《广告法》第 9/17/28 条、《反不正当竞争法》第 8 条
- 每条附**处罚区间** + 公开可核验的**真实处罚案例** + gov.cn 原文链接
  （如：屈臣氏武汉"92% 原液含量"实测 0.414%；南京某店身体乳标"美白淡斑"而备案仅"修护保湿"罚 2000 元；英德"止脱育发"套盒罚没 1.14 万元）
- 最高一档：虚假宣传 **20~100 万元**，情节严重 100~200 万并可吊销执照，消费者可主张退一赔三
- 实测 6 段真实种草文案：1 段命中违禁宣称、4 段需核对特殊化妆品注册证、1 段干净
  → **真实内容不是一片假，这组数字恰好证明我们不乱报**

## 三、诚实边界（答辩必须主动说，别等被问）

1. **跨生成器召回 66.7%** 这个数字要**改口径**：那只是最难的一组（12 张平台 ImageGen 直出、伪真实感/生活流风格）。
   在完整冻结池（38 张，含 cross/cross_native/FLUX）上，级联捕获率是 **94.7%**。两个数字都要说，并说明各自 n。
2. **频域的取向分不是概率**。刻意不叫 probability，避免和 AIGC 模型概率混淆。TEST 段每类样本仅 20 AI / 10 真实，
   置信区间宽，引用时**必须带 n**。
3. **评论区与溯源的标注集是团队自建合成**。方向命中率（6/6、5/5）只证明"特征能区分我们设定的两种模式"，
   **不能**当真实场景准确率。真实标注集仍缺失。
4. **真实评论标注集缺失** —— 这是本轮最大的已知缺口，列入待补清单。
5. 高风险必人工复核，分数不是法律结论；封号/下架这类不可逆动作一律不自动执行。
6. MJ/SD/Flux 原生图目前只有 4 张训练 + 1 张冻结（`data/ai_mj_sd_flux*`），跨生成器结论仍有样本量限制。

## 四、验证方式（一条命令跑全套）

```bash
# 1) 单元测试（108 项，含 41 项新增回归）
python -m pytest -q

# 2) 频域标定 + 冻结集评测
python tools/spectral_calib.py --refit

python tools/cascade_eval.py

# 4) 工具消融表

# 5) 三个场景的标注集评测
python tools/comment_check.py --all
python tools/trace_tool.py --all
python tools/compliance_rules.py --all

# 6) 端到端（单图，不带 --fast 才会跑 aigc/trufor）
python tools/pipeline.py data/ai/ai_17.png
```

模型 pin 防退化：所有评测脚本启动时都会 `MODEL_PRIORITY=[v4]` 并**断言解析到的目录确实是 v4**，
不满足直接退出 —— 防止静默回退旧模型却输出一份"看起来通过"的假结果（9/26 踩过）。
