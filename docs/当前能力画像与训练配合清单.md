## 一、先直接回答：现在能不能准确识别？

### 答案：**不能。实验室里看着满分，一到真实场景就崩。**

本次实测的三个数字：

| 测试场景 | 准确率 | 误报情况 | 能信吗 |
|---|---|---|---|
| **实验室受控集 35 张** | **100%**（35/35） | 真实图 0/15 误报 | ❌ **不能信**——其中 28 张是训练时练过的 |
| └ 其中"没见过的" 7 张 | 100%（7/7） | 0/3 | 🟡 样本太少，说明不了问题 |
| **真实小红书美妆图 56 张** | **34%**（19/56） | **37 张被误判成 AI（66%）** | ✅ **这才是真实水平** |

### 打个比方你就明白了

这模型像个**把题库背熟了的考生**：
- 拿练过的题考他 → 100 分
- 拿 7 道新题考他 → 还是满分（运气好，题太少）
- 拉到真实考场（56 道真题）→ **34 分，而且错的都是同一种：把"化了妆的"全当成"画出来的"**

**根因一句话**：教他认"真苹果"时，给他看的全是**带疤的、没打蜡的**（15 张原始手机照）；他于是学到歪理"**光滑漂亮 = 假**"。等上了街，看到真实但精修过的美妆照，全喊"假的！"。

## 三、需要你配合的事项（清单）

### 3.1 训练数据来源与格式要求

**① 真实美妆图（⭐ 最高优先级，直接决定误报能不能修好）**

| 要求 | 具体说明 |
|---|---|
| 来源 | 小红书/微博/电商详情页等**真实种草帖**；品牌官方图；你自己拍的 |
| **关键**：必须包含**精修过的** | 带美颜、滤镜、磨皮、调色的真实照——这正是现在误判的重灾区 |
| 内容 | 口红/粉底/眼影等美妆品类；产品静物、试色、上脸特写都要有 |
| 格式 | **jpg 或 png**（⚠️ webp 不行，脚本不认，我会转） |
| 尺寸 | **最短边 ≥ 200px**，别太小 |
| 数量 | 目标**再补 30–50 张**（现有 56 张已够开训，多补更稳） |
| 🔴 红线 | **不要**陌生人正脸、**不要**带昵称头像的截图、**不要**别人整理的素材包 |

**② 非即梦的 AI 美妆图（第二优先级）**

现在是 20 张 AI 图**全是即梦一个生成器**——答辩必被问"换 Midjourney 行不行"。

| 要求 | 说明 |
|---|---|
| 生成器 | **Midjourney / Stable Diffusion / Flux** 各来 **2–3 张** |
| 内容 | 美妆主题（口红、妆容、产品图） |
| 格式 | jpg / png |

**③ 不要给什么**
- 从别人仓库/素材包拷的图（版权风险）
- 二次截图、转发压缩过的图（会引入压缩噪声，污染训练）
- 含陌生人清晰正脸的图（隐私风险）

| 规则 | 说明 | 举例 |
|---|---|---|
| 只分两类 | `ai` = 整张由 AI 生成；`real` = 真实拍摄 | |

### 3.6 怎么评估最终准确率（**别只看一个数**）

必须三层分开测，只看任何一层都会被骗：

| 层级 | 测什么 | 达标线 | 为什么 |

| **① 真实世界集**（最重要） | 56 张小红书真实图 | 误报 **≤15%** | 这是真实水平 |

**⚠️ 评估铁律**：
- **绝不在训练用过的图上评准确率**（会虚高到 100%，自欺欺人）
- 每轮换模型都要**重跑**，别信旧的结果 json
- 额外看**弃权率**（拿不准的比例）控制在 25% 以内，太高就没法用了

## 四、在你补齐数据之前，现在怎么用才最好？

坦白说，**现阶段不能把它当判定依据**。但如果比赛演示要用，这样给输入能把误差降到最小：

| 怎么做 | 为什么 |
|---|---|
| ✅ **给原图**，别给截图/转发图 | 截图会引入压缩噪声，进一步推高误判 |
| ✅ **一次给一批**（同一来源/同一场景） | 单张的分数波动大，一批能看分布 |
| ✅ **同时给文案** | 图文交叉验证是我们真正靠谱的能力（文案说"原相机实拍"但图判 AI = 硬矛盾） |
| ✅ **明确告知图片来源** | 我能据此判断是否属于模型见过的分布 |
| ⚠️ **高风险结论必须人工复核** | 现在这个误报率，机器说"AI 生成"时你一定要自己看一眼 |

> 一句话：**现在最靠谱的是 TruFor（局部篡改定位）和图文交叉验证，不是整图 AI 判定。** 演示时把重心放前者，后者主动说明"还在校准中"——这比硬撑"我们很准"更得分。
