# BeautyProof · 数据集闭环评测报告（识别 → 决策 → 处置）

> 配套入口：`tools/run_dataset_closedloop.py`
> 产物：`results/closedloop_eval.json`
> 评测对象：统一跑 `tools/pipeline.analyze()`（全量 aigc + trufor，非 `--fast`）

---

## 0. 这份报告想证明什么

赛题 2 的两件硬要求，都靠「数据集」落地：

1. **多模态检测是否识别出真伪痕迹** → 看 `risk_level` 分布与「方向命中率」；
2. **Agent 是否给出风险预警与处理建议，形成识别→决策闭环** → 看四档风险落到哪种处置（处置建议分布）。

本报告不堆「准确率 100%」的漂亮话，而是把**每一档风险对应什么处置、哪些口径是真 held-out、哪些是受控**讲清楚 —— 这是评委最看重的「诚实闭环」。

---

## 1. 闭环主线：识别 → 决策 → 处置

| 阶段 | 谁产出 | 输出 | 流向 |
|---|---|---|---|
| **识别** | 6 工具（hash/c2pa/ela/ocr/aigc/trufor）+ 规则引擎 `judge()` | `risk_level` ∈ {high_risk, suspicious, credible, inconclusive} + `reasons`（可解释依据） | 进入 Agent |
| **决策（预警）** | `planner.decide_actions()`（规则 A1–A3） | 风险档 → 预警动作（进复核队列 / 待人工确认 / 核改文案 / 核实来源） | 进入处置统计 |
| **处置** | 证据链 + 热力图 + 人工复核工作台 | 处置建议分布（disposition 计数） | 评委可见的闭环终点 |

**四档风险 → 处置映射（核心口径）**

| 风险档 | 含义 | 默认处置（disposition） |
|---|---|---|
| `high_risk` | 高风险：整图 AI 生成 / 明显篡改 / 图文硬矛盾 | 自动进入人工复核队列（A1） |
| `suspicious` | 可疑：有迹象但不足定性 / 文案违规宣称 / 图文口径不一 | 标记待人工确认（A1）；若命中违规宣称再叠加核改文案（A2） |
| `credible` | 可信：带 C2PA 凭证、编辑历史可查 | 可正常使用，留存凭证备查 |
| `inconclusive` | 无法判定：工具没发现明确问题，但也不能证明一定真实 | 如需确证，向品牌方索取带凭证原图 |

> 处置建议来源：聚合 `planner.decide_actions()` 返回的 `action` 字段（即处置 playbook 的 disposition）。

## 2. 评测口径与纪律

| 数据集 | 真值 | 期望命中档 | 口径归属 | 是否参与训练 |
|---|---|---|---|---|
| `data/clean/` | clean | inconclusive / credible | 受控 | 否 |
| `data/tampered/` | tampered | suspicious / high_risk | 受控 | 否 |
| `data/ai/` | ai | high_risk | 受控（本域微调覆盖族：即梦等） | 是（微调用） |
| `data/realworld_heldout/` | real | inconclusive / credible | **真 held-out** | **否（铁律）** |
| `data/ai_cross_native/` | ai | high_risk | 零样本跨生成器（同生成器族、非 MJ/SD/Flux） | 否 |

**方向命中率** = 该集 `risk_level` 落入「期望档」的比例。

**口径纪律（不可破）**：
- **真实误报率对外只报 `realworld_heldout` 那个数**。受控集（clean/tampered/ai）真值已知、规模小，只证明「链路能判对」，不代表真实世界鲁棒性。
- **跨生成器零样本召回只到同生成器族**：本系统在即梦（同族）上做过微调，对 MJ/SD/Flux 外推能力未验证，绝不把「ai 集 high_risk」冒充成「通用 AI 检测准确率」。

## 4. 诚实边界（必须主动讲，不等评委问）

1. **受控集 ≠ 真实鲁棒性**：clean/tampered/ai 是造的小样本，真值已知，用于验证「链路判得对」，规模小（合计 ≤ 25 张），不该被解读为泛化能力。
2. **真实误报只认 held-out**：`realworld_heldout` 10 张取自真实世界、永不回灌训练，是唯一对外的「真实图不误报」证据。若 held-out 误报率偏高，才是真问题。
3. **AI 检测是「本域微调」而非「通用」**：`data/ai` 的 high_risk 来自即梦等同族微调模型；换 MJ/SD/Flux 的零样本能力由 `ai_cross_native` 单独报，且明确只到同生成器族，不外推。
4. **`inconclusive` 不是「真」**：多数网图本就无可查凭证，「没查出问题」≠「证明没问题」，报告里一律写清。
5. **算法结论 ≠ 法律结论**：四档风险是风险预警，最终处置需人工复核（high_risk 按纪律必进人工队列）。
