## 三、奖项与奖金区间预测

奖金池 20 万：一档 8 万(1) / 二档 3 万(2) / 三档 1 万(3) / 单项 5 千(3，技术·商业价值·公益赋能) / 明日之星 3 千(5)；决赛共 14 支队伍。

| 结果 | 概率 | 奖金 |
|---|---|---|
| 未进决赛 | 75%–85% | 0 |
| 进决赛但无奖 | 5%–8% | 0（有证书/实习直通机会） |
| **明日之星（3 千）** | **4%–6%** | 3 千 × |
| **单项奖（5 千）** | **4%–6%** | 5 千 —— 我们最可能命中「技术」或「公益赋能」单项 |
| 三等奖（1 万） | 2%–4% | 1 万 |
| 二等奖（3 万） | 1%–2% | 3 万 |
| **一等奖（8 万）** | **1.5%–3.5%** | 8 万 |

**期望奖金**：粗略加权约 **2 千–5 千**（概率×金额求和）。也就是说：**冲奖的现实目标是"单项奖 / 明日之星"，不是一等奖。**

> 一个诚实的对照：一等奖要的是"技术突破 + 完整落地 + 现场说服力"三项都强。我们**落地是弱项**（无真实数据、无客户），这一项短时间内补不齐。

## 五、我的建议（直说）

**别把一等奖当目标，把"单项奖 + 进决赛"当目标。**

理由：一等奖要求"技术 + 落地 + 现场"三项都强，而我们的**落地验证是结构性缺口**（要真实客户/真实数据，4 天内补不齐）。但我们在**技术单项**上有真实优势：

- 工具消融（证明编排是贡献，不是堆料）——同侪基本不会做
- 双检测器级联 94.7% 零误伤——有冻结池数字撑着
- 第九件工具标识层救回 7/7 + 真实图 0 误报——有代价函数、有边界声明
- 负面结果主动归档 v5/v7——诚实度是差异化卖点

**所以 4 天里最该做的三件事**（按 ROI 排序）：
1. **补真实评论标注集**（50 条）——直接补官方第 1 维度 + SCALABLE，是三个缺口里唯一"补了就能改分"的
2. **PPT 配图 + 视觉锚点**——评委翻 PPT 的前 30 秒决定印象分，这是最便宜的分
3. **3 次真人实测留痕**——EMPATHY 从 0 变有，成本 1 小时

三件都做完，进决赛概率从 15%–25% 能提到 **25%–35%**；一等奖概率从 1.5%–3.5% 提到 **3%–6%**。还是不到 1/10，但这是 4 天内能做到的极限。
