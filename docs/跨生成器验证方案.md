# 跨生成器验证方案（Midjourney / Stable Diffusion / Flux）

> 目标：堵死评委那句必问的质疑——**「换个 AI 生成器画，你还认得出来吗？」**
> 配套脚本：`tools/_validate_crossgen.py`

---

## 0. 一句话现状（答辩照这个口径说，别夸大）

| 项目 | 状态 | 证据 |
|------|------|------|
| 即梦（训练域生成器）内 AI 图召回 | ✅ **100%** | 受控评测集 |
| v3 在**自产图池**上的 held-out 跨子集召回 | ✅ **25% → 100%** | `tools/train_aigen_v3.py` 干净 held-out 划分 |
| **真·第三方生成器**（MJ / SD / Flux）零样本召回 | ⏳ **尚未验证** | 缺队友素材，本文档即为补齐方案 |

**关键区分（务必讲清，这也是我们的诚实加分项）**：
上表第二行的「跨生成器 100%」是在**我们自己用 ImageGen 生成的图池**里做干净划分后测出的。
它证明的是「模型没有把训练图背下来」，**不等于**「能认出 Midjourney / SD / Flux」。
第三行才是评委真正要问的东西，目前仍待队友素材到位后实测。

---

## 1. 为什么必须做这一项

- 训练数据全部来自单一/自产生成器，是本项目**最大的技术攻击点**。
- 竞赛规则与自查文档已多次点名：`docs/能力匹配与自查_结构化报告.md` 第 6 条、
  `docs/开源方案检索.md` 痛点 B、`docs/incoming_素材利用方案.md` 方案 D，
  都把「拿 MJ/SD/Flux 真图实测」列为**答辩必问项**。
- 主动暴露边界 + 给出验证路径，比硬撑「我们全都测过」更得分（对齐 JUDGMENT 支柱）。

---

## 2. ⚠️ 重要警告：不要把现有自产图当成第三方生成器证据

仓库 `data/ai_cross/` 目前有 26 张图（`cross_01~08.png` + 18 张带时间戳的 ImageGen 图），
但**它们不能用来宣称「已通过 MJ/SD/Flux 验证」**，原因有二：

1. **它们是我们自己用 ImageGen 生成的**（见 `docs/SOURCES.md` §1.7 数据来源），
   不是 Midjourney / Stable Diffusion / Flux 的产物。
2. 其中一部分**已参与 v3 的训练或 held-out 划分**。在训练/划分见过的图上评准确率会虚高到 100%，
   属于自欺欺人——这正是本项目踩过并写进教训的坑
   （铁律：**绝不在训练用过的图上评准确率**）。

> 所以：第三方生成器的结论，**只能来自队友提供、且未参与训练的真图**。

## 3. 执行步骤（队友素材一到，约 7 分钟出结果）

### 第 1 步：建目录
```

    mj/      ← Midjourney 图（2~3 张）
    sd/      ← Stable Diffusion 图（2~3 张）
```

`mj` / `midjourney`、`sd` / `stable-diffusion` / `stable_diffusion`、`flux`。

### 第 2 步：放图
- 必须是**美妆主题**的 AI 生成图（与本域一致，否则测的是域偏移不是生成器偏移）。
- 必须**未参与过 v3 训练**（队友新给的图天然满足）。
- 格式支持 `.png .jpg .jpeg .webp .bmp .gif`。

## 4. 判定口径

| 阈值 | 含义 |
|------|------|
| `ai_prob >= 0.5` | 记为「命中 AI」（召回率口径） |
| `ai_prob >= 0.8` | 记为「高置信命中」（更严格的口径） |

`ai_prob` 由 `aigc_tool.run_aigc()` 给出，即「整张图由 AI 生成」的概率。
脚本自动走 `MODEL_PRIORITY`，**优先使用 v3**（`models/beautyproof_aigen_v3`），v2 兜底。

## 5. 结果怎么解读、路演怎么讲

**情况 A：三个生成器召回都高（理想）**
> 「我们专门做了零样本跨生成器验证：MJ / SD / Flux 各 2–3 张真图，
> v3 未针对它们训练，召回仍达 X%。这堵死了『换个生成器就不灵』的质疑。」

**情况 B：某个生成器召回低（同样有得讲，甚至更得分）**
> 「我们主动说明边界：v3 对 Flux 的召回是 X%，低于即梦域的 100%。
> 原因是训练池以单一/自产生成器为主。我们已经把『扩生成器样本 + 重新校准』
> 列为下一步，并且线上对低置信样本设置了**弃权阈值（0.2）交人工复核**，
> 不会在没把握时硬判。」

**统一策略：先给结论 → 再给数字 → 最后主动补边界。**
主动暴露边界 = 可信度来源（见 `docs/路演叙事.md` 的 Q&A 预埋）。
