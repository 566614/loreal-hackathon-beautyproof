## 4. 真实跑一次：一张图 + 一段文案

准备一张你自己的图（任何美妆相关图片都行），然后**连文案一起送进去**——
这才是完整形态（赛题要求的是「文案与图片」双模态）：

```bash
./run.sh tools/pipeline.py <你的图片路径> --text "原相机实拍，无滤镜，七天美白亲测有效"
```

想先快速看效果（跳过深度学习模型，秒出）：

```bash
./run.sh tools/pipeline.py <你的图片路径> --fast
```

想导出 PDF 给法务 / 品牌方存档：

```bash
./run.sh tools/pipeline.py <你的图片路径> --pdf
```

**你会拿到什么：**

| 产物 | 位置 | 内容 |
|---|---|---|
| 逐工具证据 | `outputs/<tool>_<文件名>.json` | 统一格式 `{tool, observed, cannot_prove, evidence[]}` |
| 汇总判定 | `outputs/analysis_<文件名>.json` | 含 `agent` 字段（Agent 跳过了什么、依据哪条规则） |
| 人话报告 | `reports/report_<文件名>.md` | 一句话结论 / 为什么 / 建议下一步 / 提醒 |
| TruFor 热力图 | `outputs/` 下 | 篡改区域定位图 |

也可以用网页版（推荐给评委）：

```bash
./run.sh web/app.py    # 打开 http://127.0.0.1:5000 拖图进去
```

## 5. 人工复核流程（高风险必须走这一步）

系统的定位是「把高风险挑出来给人看」，**不是替人下最终结论**。所以跑完之后要走复核：

```bash
./run.sh web/review_app.py     # 人工复核工作台：复核结论留痕
```

批量审核（一天审成百上千张的场景）：

```bash
./run.sh tools/batch_review.py    # 输出 CSV / JSON / 静态看板
```

**复核要看的三件事：**
1. 报告里的 `cannot_prove`（本次证明不了什么）—— 这是最容易被人忽略、也最能体现可信度的一栏；
2. TruFor 热力图命中的区域，跟人眼看到的是不是一回事；
3. 判定为 `suspicious` 的样本多半是「贴着阈值线」，务必人工确认，不要直接采信。

## 8. 卡住了先看这里

| 现象 | 原因 / 处理 |
|---|---|
| `setup_trufor.py` 体检不全 OK | 网络没拉全权重，重跑一次；仍不行看该脚本输出的提示 |
| import 报 `HF_ENDPOINT` / 连不上 HuggingFace | 按第 2 节设 `HF_ENDPOINT=https://hf-mirror.com` |
| 报告里 C2PA 显示「未就绪」 | **正常**，c2patool 是可选依赖；缺失只会跳过，不会误判可信 |
| `pipeline.py` 很慢 | 先加 `--fast` 跳过深度学习模型预览；确认要深检再跑 full |
| 中文路径导致写图失败 | 本项目落盘统一用 `cv2.imencode + write_bytes`，如遇异常请把图放到纯英文路径下重试 |
