## 二、针对 BeautyProof 三大痛点的筛选结论

### 痛点 A：真实世界美妆图 66% 误报（模型过拟合"精修=AI"）
- **根因**：本域模型训练真实样本仅 10 张原始手机照，没见过"真实但被美颜/滤镜精修过的美妆照"。
- **最对症方案（两条路，不互斥）**：
  1. **FSD（零样本）**：它只学"真实照片的微观纹理统计"，**从不在合成数据上训练**，天然不会被"精修美妆照"骗成 AI——直接命中痛点 A。代价：CC-BY-NC-SA-4.0 非商用 + 速度 ~0.11 图/秒（批处理可接受）。
  2. **自有无授权风险重训**：用已有的 **56 张小红书真实美妆图** 扩充真实集（目前仅作测试集，可转训练），+ 加**弃权阈值**（低置信度交人工）。这是 100% 自有模型、零外部协议风险，是最稳的落地路径。
- **capcheck 已排除**：实测中文美妆域全判 human≈0.99，不能解决。

### 痛点 B：单一生成器缺口（只覆盖即梦）
- **FSD** 在 24 个生成器上 96% AUC，含 Midjourney/DALL-E/SD/StyleGAN，**零样本跨生成器**——直接补 B。
- **Few-Shot-AIGI-Detector** + **GenImage** 数据集：可作为"拿到新生成器样本后快速适配"的备选。
- **仍建议**：向阮要 2–3 个非即梦生成器（Midjourney/SD/Flux）的 AI 美妆图，建 `data/ai_cross/` 做零样本跨生成器实测，验证 FSD 与自训模型在真实美妆域的外推力。

### 痛点 C：Agent 解释层对齐（"为什么判 AI"）
- **FakeShield / AIGI-Holmes / ThinkFake / LEGION / Veritas** 是"检测 + 定位 + 自然语言解释"范式，与 BeautyProof Agent 的"每轮出证据 + 方位大白话结论"目标一致。
- 但这类 MLLM 方案**当前 CPU 环境跑不动**（FakeShield 明确要 CUDA）。建议：**设计上对齐其解释范式，工程上暂不集成重模型**；轻量解释可由现有 6 工具证据 + TruFor 热力图 + FSD 的 z-score 方向拼出，不必上 LLaVA。

## 三、推荐落地路径（按优先级）

1. **立即做（零协议风险、直接修误报）**：把 56 张小红书真实美妆图从测试集转训练集，重训本域 AIGC 模型 + 加弃权阈值（低置信交人工）。产出新 `models/beautyproof_aigen_v2`。
2. **并行评估（补跨生成器）**：本地跑 FSD 的 `FSDDetector.score_batch()` 对 `data/ai/`（即梦）+ `data/real/` + 56 张 XHS 真实图 打分，验证其零样本能力在美妆域是否真的压过自训模型。**仅用于评测/对比，不直接作为线上检测器**（CC-BY-NC-SA 非商用）。
3. **建跨生成器测试集**：收 2–3 个非即梦生成器美妆图 → `data/ai_cross/`，FSD + v2 同场实测。
4. **解释层（设计对齐，非重模型）**：复用 FSD z-score 方向 + TruFor 热力图 + 现有证据，产出"大白话结论"，不引入 MLLM。
5. **前沿跟踪**：收藏 `awesome-aigc-image-detection`；关注 Venus-DeFakerOne（若出 CPU/量化版或宽松协议，未来可升级）。

## 四、风险与待确认

- ⚠️ **FSD 协议风险**：CC-BY-NC-SA-4.0 = 非商用。黑客松竞赛 + 可能商业化的方案，**不能直接作为线上检测器部署**；仅可用于评测对比与算法参考。若需商用检测，优先走"自训 v2"路径（自有模型无此限制）。
- ⚠️ **FakeShield 等 MLLM 环境不兼容**：本机 CPU 无 CUDA，LLaVA/SAM2 类模型推理极慢甚至无法加载，当前不可行。
- ⚠️ **多项目协议待核实**：DeepGuard、Few-Shot-AIGI-Detector、GenImage、AIGI-Holmes 等协议未在检索中确认，集成前必须逐一看 LICENSE。
- ✅ **已实测排除**：capcheck 在中文美妆域完全失效（全判 human），不再考虑。
- 📌 **数据授权**：56 张小红书图来自 MediaCrawler 抓取，版权归原作者，**仅内部测试、不入库不公开**（已在 `outputs/_external_xhs/` 且未提交）。

## 五、一句话结论

**修误报 + 补跨生成器的最快路径是自训 v2（56 张真实美妆图 + 弃权阈值，零协议风险）；FSD 是算法层面最对症的零样本方案但受非商用协议限制、只作评测对比；可解释方向对齐 FakeShield 范式但当前 CPU 环境跑不动重模型，用现有轻量证据拼解释即可。**
