# 跨生成器重训与素材获取（MJ / SD / Flux）

## 目标
把「跨生成器零样本召回」从旧基线 **~58%（7/12）** 尽量提升（生产模型实际 66.7%=8/12），并把真实世界误报率（held-out）作为唯一对外鲁棒性口径如实汇报。
> 诚实说明：本 MIT 源只能取到 **Flux**，SD / MJ 无法逐文件获取（见下）；且 12 张零样本里有 6 张「生活流/滤镜自拍」难例，模型对其自信判真，**仅凭少量 Flux 难以突破 80%**。下列工作是把能做的合规动作做实，而非虚报达标。

## ⚠️ 为什么不能直接盲爬「AI 美妆图」
- 网页/社交平台上的「AI 美妆图」**标签极不可靠**：很多是真实模特/网红照片被当 AI 图发，或反之。
  一旦把真实人脸错标成「AI」塞进训练，会直接摧毁我们「真实美妆图低误报」这一核心优势
  （项目早期已吃过 66% 误报的大亏）。
- 项目红线：训练数据全部团队自产 / 来源清晰，**不爬无标注第三方数据集、不用 GenImage/COCO/ImageNet(训练集)**。
- 故：跨生成器素材必须「**可证明为 AI 生成 + 来源清晰 + 合成无真人肖像权风险**」。

## ✅ 合规来源与可得性（已实测，2026-09-28）
**SFHQ-T2I**（SelfishGene，Kaggle，[MIT 许可](https://www.kaggle.com/datasets/selfishgene/sfhq-t2i-synthetic-faces-from-text-2-image-models)，122K 合成脸）
- 由 Flux1.pro/dev/schnell、SDXL、DALL·E 3 生成，**逐张带 model+prompt+seed 元数据** → 来源可证。
- 全部**合成脸，无隐私/肖像权问题**，MIT 许可可研究/比赛使用。
- **可得性实测结论（重要）**：经 Kaggle API 逐文件下载，该数据集**仅 `a_small_sample_new/FLUX1_dev_*` 可单文件取到**；
  主数据集（24GB）不暴露单文件、整包不可行；SDXL / DALL·E 3 / MJ 在本环境**无法逐文件获取**。
  GitHub 仓库 `SelfishGene/SFHQ-T2I-dataset` 只含生成脚本，**不托管图片**。数据集作者亦注明 DALL·E 3 人脸图质量很差、不建议用。
- 因此：本源**只能提供 Flux** 一类生成器；SD、MJ 需另寻合规源（目前未找到可逐文件获取且无真人风险的 MIT 镜像）。

## ⚠️ 关于「Midjourney」的特殊说明
SFHQ-T2I **不含 Midjourney**。要合法拿到 MJ 合成图，最稳妥是**本人订阅生成**（即梦/订阅类同），目前未提供。
若后续补充 MJ，放入 `data/ai_cross_native_incoming/midjourney/` 并逐张登记 PROVENANCE 即可，收编脚本会自动纳入。

## 阮的操作（若日后补充 SD / MJ / 更多 Flux）
1. 登录 Kaggle（免费）→ 打开 SFHQ-T2I 数据集页 → 用 Kaggle API 逐文件下载 `a_small_sample_new/FLUX1_dev_*`；
   或本人订阅生成 Flux/SD/MJ 美妆人像。
2. 放到 `data/ai_cross_native_incoming/<生成器>/`，在每个子目录的 `PROVENANCE.md` 逐张登记：文件名 / 生成器 / 提示词 / 来源 MIT / 是否合成(无真人)=是。
3. 跑收编 + 重训：
   ```bash
   python tools/collect_crossgen.py --heldout-per-generator 4
   python tools/train_aigen_v6.py
   ```
4. 重跑闭环评测确认（诚实口径）：
   ```bash
   python tools/run_dataset_closedloop.py --from-outputs --require-full-coverage
   ```

## 已就绪的 machinery（本仓库）
- `tools/collect_crossgen.py`：校验每个生成器子目录必须有 `PROVENANCE.md`，无来源标注一律拒绝；
  自动切出少量作零样本验证集（`data/ai_mj_sd_flux_heldout/`，永不训练），其余进训练。
  （已修：对不存在的生成器子目录直接跳过，不再报错。）
- `tools/train_aigen_v6.py`：在 v5 基础上把 Flux 跨生成器图并入训练（递归读取 `data/ai_mj_sd_flux/`），
  `data/ai_cross_native/`（原 12 张）与 `data/ai_mj_sd_flux_heldout/` 始终作零样本测试。
  - **`data/ai_cross`（26 张 ImageGen）维持整体 held-out**（reviewer P1，且与 ai_cross_native 零重叠）：
    实测把 ai_cross 纳入训练反而稀释模型对 ai_cross_native 难例的判别力（零样本召回由 66.7% 掉到 50%），已回退。
- `data/ai_cross_native_incoming/PROVENANCE_TEMPLATE.md`：登记表模板与字段说明。
- `tools/eval_v6.py`：加载已训练 `model.pt` 秒级复算跨生成器零样本召回与验证集混淆（无需重训）。

## 当前诚实基线（results/closedloop_eval.json，gate_passed=true）
- 受控集方向命中率：clean 100% / tampered 100% / ai 100%
- **真实世界 held-out 误报率 = 20%（2/10：1 high_risk + 1 suspicious）** ← 对外唯一鲁棒性口径
- **跨生成器零样本召回 = 66.7%（8/12，漏 crossgen_04/09/10/12）** ← 难例为生活流/滤镜自拍风格
- 篡改召回（按类型）：copy_move/splice/text_edit 均 100%

## 2026-09-28 实测记录（诚实归档）
- 用户授权用其 Kaggle token（KGAT_…）下载 SFHQ-T2I。经实测：**仅 FLUX1_dev 可逐文件下载**（5 张，落 `data/ai_cross_native_incoming/flux/` 并已写 `PROVENANCE.md`，prompt 取自数据集 CSV）。
- SDXL / DALL·E 3 / MJ：**该数据集不暴露单文件、整包 24GB 不可行**，GitHub 仓库只含脚本。**未取到**。
- 把 `ai_cross`（26 张 ImageGen，与 ai_cross_native 零重叠）纳入训练的尝试**导致回归**（零样本召回 50%），已回退为 held-out。
- v6 已修 `_img_files` 非递归导致的 Flux 漏读 bug，Flux 现可真正进训练；重训后按 eval_v6 实测指标决定是否超越 v4 基线（66.7%），不可达 80% 时以 v4 为生产模型、如实汇报。
- 结论：**≥80% 目标受「难例风格 + 仅 Flux 可得」双重限制，本环境无法达标**；已把能做的合规动作（Flux 收编+训练+评测链）做实，杜绝虚报。
