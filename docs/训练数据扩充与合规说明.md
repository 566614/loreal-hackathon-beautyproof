# 训练数据扩充方案与合规说明（赛题2 · 请求 J）

> 目标：在「训练图片数量不足、模型能力有限」的前提下，于赛题2 规则严格约束内扩充训练数据、
> 增强模型整体能力。所有手段必须**只用允许的数据与机器学习标准方法**，不得引入规则外数据或方法。

---

## 一、赛题2 合规边界（先定红线，再动手）

赛题2「信任守护师」的约束可落到两条：
- **原创性 / 不侵权**：参赛代码、算法模型及方案必须原创，不得侵犯第三方知识产权。
- **数据 / 代码来源合法合规**：数据来源与使用过程需合法合规，无实质创新贡献的队伍可被淘汰。

据此划出**红线**与**允许区**：

| 类别 | 是否允许 | 理由 |
|------|----------|------|
| GenImage（CC BY-NC-SA，**非商用**） | ❌ 禁止入训练 | 20 万元奖金属商业场景，与「非商用」授权冲突；且其域（艺术/新闻图）与美妆域不匹配，实测区分度差 |
| COCO | ❌ 禁止 | 与美妆鉴伪无关 + 含人脸隐私风险 |
| ImageNet 当**训练集** | ❌ 禁止 | 属第三方大规模训练库；但**仅作骨干初始化权重**是允许的（已在 config.json 披露） |
| 任何第三方数据集 / 外部爬取 | ❌ 禁止 | 违反「数据来源合规 + 原创性」 |
| 团队**自产标注图**（即梦生成 + 用户/队友提供的真实美妆图） | ✅ 允许 | 自有数据 |
| 纯图像处理**数据增强**（域增强） | ✅ 允许 | 机器学习标准做法，无外部数据 |
| 对**团队自产未标注**真实美妆图做**伪标注 / self-training** | ✅ 允许 | 数据全部自有，不外采 |
| **决策边界 / 弃权带调优**（纯参数） | ✅ 允许 | 不引入任何数据或外部方法 |

> 关键判断：**真正能增强「真实美妆图分布覆盖」的，是扩充自有真实图 + 域增强 + 弃权带，
> 而不是去拿 GenImage/COCO 这类规则外大库。** 后者即便技术上能涨点，也会直接踩合规红线、吃掉原创性评分。

## 二、已落地的 4 个高 ROI 手段（全部合规）

### 手段 1 · 域感知数据增强（已落地：`tools/beauty_aug.py`）
真实痛点是：真实美妆图普遍带「滤镜 + 磨皮 + 重度 JPEG 重压缩 + 平台缩放」，而训练真实图只有 ~84 张。
增强模块补强「真实美妆图分布」覆盖：
- `RandomJPEG`（社交/微信重压缩伪影）、`RandomResizeNoise`（被缩小再放大的平台缩放伪影）、
  `RandomGaussianNoise`（传感器/压缩噪声）；
- 更强 `ColorJitter`（滤镜/色调）、小幅 `RandomRotation`、`GaussianBlur`（近似磨皮）。
- 全部只作用在已合法取得的自产图上，无外部数据、无第三方权重依赖。

### 手段 2 · 增强接入训练（已落地：`tools/train_aigen_v3.py` 改造）
v3 训练脚本已改为 `from beauty_aug import get_train_transform, get_infer_transform`，
用域增强替换旧 transform。训练分布更贴近「美颜后的真实美妆图」，直接压低真实图误报。

### 手段 3 · 伪标注扩充 REAL 类（已落地：`tools/pseudo_label.py`）
用已上线的本域微调模型，对团队**自产、未标注**的真实美妆图（`data/xhs_real_unlabeled/`）做 self-training：
- 模型高置信判为「真实」（`ai_prob ≤ 0.25`）→ 复制到 `data/real_extra/`，纳入 REAL 训练池；
- 高置信判为「AI」（`ai_prob ≥ 0.5`）→ 排除并记入清单（提示人工核实是否 AI 图混入）；
- 模糊带（0.25~0.5）→ 跳过，交人工。
- 产出 `results/pseudo_label_real.json` 清单（每张图处置 + 分数），**全程可核查**。
- 这是标准 self-training 手段，数据全部团队自有，**未引入任何第三方数据集**。

### 手段 4 · 决策边界 / 弃权带调优（已落地：`tools/aigc_tool.py` 改造）
真实美妆图经重度美颜/滤镜后常被旧 `0.5` 阈值误判为 AI。把「判为 AI 生成」的阳性阈值上调到 **0.6**，
并在 `[0.5, 0.6)` 设「无法单独定性」模糊带（交规则引擎 + 人工复核）。这是训练数据少时**最稳的稳压手段**：
纯参数调整、零数据引入、比盲目加数据更可控，直接降低真实图误报。

### 手段 5（集成）· v4 训练入口（已落地：`tools/train_aigen_v4.py`）
在 v3 基础上集成上述全部：域增强 + 并入 `data/real_extra` 伪标注真实图 + 保留跨生成器 held-out 评测。
模型来源披露与 v3 一致（骨干 = ImageNet-1k 权重，仅初始化）；`config.json` 新增
`augmentation` / `data_expansion` / `pseudo_labeled_real` / `compliance` 字段，机器可核查。
`aigc_tool.MODEL_PRIORITY` 已把 v4 置顶，未训练时权重缺失会自动回退 v3（安全）。

## 三、关于「强化学习」的处理（用户建议，已评估）

用户建议「运用机器学习、**强化学习**等可行手段」。评估结论：**当前阶段不采用 RL**，理由如实说明：

1. **数据量太小**：本域标注图仅 ~135 张（v3），二分类且已接近饱和（val_acc 0.963、跨生成器召回 1.0）。
   RL 需要大量交互样本与稳定奖励信号，在百张级数据上极易过拟合、训练不稳，收益不确定。
2. **监督 + 域增强 + 弃权带已是更优解**：误报的根因是「真实美妆图分布没覆盖」，靠**扩充真实图分布
   （伪标注）+ 域增强 + 阈值校准**比 RL 更直接、更可解释、更稳。
3. **RL 的潜在收益在这里不成立**：RL 通常用于「策略/序列决策/探索-利用」，而本任务是静态图像二分类，
   没有天然的可学习策略空间；把分类阈值当 action 做 RL 反而比直接调参更脆弱。

> 若后续数据规模扩大到千张级、且需要自动搜「阈值/增强强度组合」以最大化「AI 召回 + 真实图低误报」
> 的复合指标，可把**弃权阈值 + 增强强度**作为 action、以验证集 FPR/召回加权为 reward，做一个轻量 RL 调参层
> （仍只用自有数据）。这属于「调参自动化」，不引入外部数据，合规。当前先不上。

## 四、运行顺序（在用户机器上，经 `./run.sh` 或 venv）

```bash
# 0) 准备：把团队自产/收集的真实美妆图（非 AI）放进 data/xhs_real_unlabeled/
# 1) 伪标注扩充 REAL 类（产出 data/real_extra/ + results/pseudo_label_real.json）
python tools/pseudo_label.py
# 2) 训练 v4（域增强 + 伪标注真实图 + 跨生成器 held-out 评测）
python tools/train_aigen_v4.py
# 3) 验证模型已自动置顶：pipeline 跑图即走 v4；没训出来则自动回退 v3
```

> 注意：`data/xhs_real_unlabeled/` 为空时 `pseudo_label.py` 会友好提示并退出，不会报错；
> 此时 `train_aigen_v4.py` 退化为「v3 + 域增强」版（仍比旧 v3 强），可随时先跑。

## 五、诚实边界（答辩要主动说）

- 跨生成器召回虽在 held-out 上达 1.0，但 `ai_cross` 仍是「ImageGen 风格」的 AI 美妆图，
  **不等同于真实 MJ / SD / Flux 原生图**；换生成器仍需重新校准。
- 模型分数**不是法律结论**，高风险必人工复核（已在证据 `cannot_prove` 字段与弃权带中体现）。
- 训练数据规模仍小（百张级），靠增强 + 伪标注 + 弃权带把分布补到够用，但**不能当司法鉴定**。
