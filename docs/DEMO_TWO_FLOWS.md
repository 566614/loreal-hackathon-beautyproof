## 企业：退货破损审核

选择「我是企业审核人员」，上传一张 JPG/PNG 原文件，直接发送或点击「审核退款破损」。走当前本地 CPU 模型，显示「更像 AI 生成 / 不太像 AI 生成 / 暂时难判断」及 0–100 的「像 AI 的程度」。红色表示更像 AI，绿色表示不太像，橙色表示难判断；没有有效结果时不显示分数。阈值、原始小数、模型名称和 CPU 等内部信息不出现在用户报告中，可在补充材料中框选看轮廓。

展示分按 `clip(round(50 + 50 × (原始分 − 阈值) / abs(阈值)), 0, 100)` 转换（阈值为零时分母取 1）；颜色沿用原始阈值上下 20% 的分档。这只是单调的展示指数，不是经过统计校准的概率；原始分、阈值与本地判定仍保存在接口中，权重和检测逻辑不变。选区仍没有独立校准分类，不得把无效选区当成低风险。

## 消费者：种草核验

选择「我是消费者」，点「附图」同时选中以下两张图片，再点击「分析这组种草素材」并发送：

- `D:/downloads/pic/微信图片_20261119194058_279_139.jpg`：完整笔记和可见评论。
- `D:/downloads/pic/微信图片_20261119194054_277_139.jpg`：手持商品宣传配图。

最多 6 张图、合计小于 32 MB。补充材料可填写纯文字正文、评论和自己的肤质、肤色、耐受情况。

报告分为广告、效果、适合谁、评论、说法、图片和可参考线索。目录默认每类只列一条，点分类可查看该类其他线索。每条线索用短标题和一句话解释；原文和参考资料默认收起，图片保留对应位置。框表示材料位置，不是伪造掩码。推荐录制以下操作：

1. 「效果」查看 8800颗、807纳米、5.39倍缺少试验出处。
2. 「评论」查看评论重复卖点，以及作者引导搜索商品。
3. 「说法」说明图文一致不等于效果证实。
4. 「可参考」保留不粘、服帖等有限主观体验。
5. 追问「这些评论都是水军吗？」「哪些内容可以相信？」「适合油皮吗？」。

两端报告按「醒目结论 → 线索目录 → 证据详情」排列，「分析过程」放在聊天回复中，默认收起，点开查看简短的公开分析摘要。真实调用成功时显示「DeepSeek 分析」。消费者的「判断把握」以 0–100 展示，注明「仅供参考」，表示 Agent 对本次结论的主观把握，未经业务样本校准，也不是广告概率。消费者摘要由通过来源检查的分析项整理；企业摘要引用本地结果，不向用户复述阈值等术语，也不改写本地判定。不会返回模型内部逐字推演或把分数解释成已证实骗赔。

## Agent、知识库和样例来源

`tools/seed_review.py` 负责材料拆分、轻量检索、DeepSeek 综合分析和引用检查。`/api/agent/turn` 保留原入口，消费者回合由种草分支处理；企业默认送图走破损分支，原宣传审核接口仍保留。

配置 `DEEPSEEK_API_KEY` 后，勾选语义辅助会调用现有 `llm_explainer.deepseek_json`。`BP_DEEPSEEK_MODEL` 和 `BP_DEEPSEEK_BASE_URL` 沿用现有配置；密钥放服务进程环境，不写入代码。发送给 API 的是文字观测和参考摘录，不是图片像素。

录制指定样例的文字、位置和分析已人工核对，按上传文件 SHA-256 精确匹配。服务未配置密钥或调用失败时，使用这份已审阅案例与本地规则；内部 `engine` 记为 `reviewed_case` 或 `local_rules`，真实调用成功后记为 `deepseek`。前端不出现 mock 标签，也不虚构 API 调用、检测概率或图片真假结论。未知图片不会套用该样例，使用可用的 PaddleOCR，无法读取时提示补文字。

`linqingxuan_case.json` 保存两张材料的审阅文字、近似归一化框、来源与逐项分析；`confirmed_ad_case.md` 保存送审方确认的广告正例与识别边界。商业推广标签由送审方明确提供，不代表已核验交易合同。评论一致性不足以确认水军，平台折叠与删除提示不能证明作者删除差评。

## 运行

前端在 `web/frontend` 执行 `npm ci`、`npm run build`。本机已准备的 Python 位于 `.submission_work/bp-next/venv-cpu/Scripts/python.exe`。可在项目根目录运行：

```powershell
& ./.submission_work/bp-next/venv-cpu/Scripts/python.exe -B -m flask --app web.app run --host 127.0.0.1 --port 5011
```

打开 `http://127.0.0.1:5011/`。若录制服务已运行，无需重复启动。

针对新功能的检查：`python -B -m pytest -q tests/test_seed_review.py tests/test_agent_workbench.py tests/test_damage_review_web.py`。
