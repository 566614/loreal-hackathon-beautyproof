# BeautyProof · 公益社会价值叙事

> 申报奖项：欧莱雅黑客松「公益赋能奖」｜ 对齐评分维度：社会价值（估权重 ~15%）
> 一句话：**我们做的不只是检测工具，而是一把帮普通人拿回"判断力"的放大镜——让真实，重新成为可以被相信、被验证的事。**
> 口径红线：本工具**不声称司法鉴定 / 法律结论**，分数仅为风险参考，高风险必人工复核（见 README 合规边界）。

---

## 一、问题：当"完美"被零成本批量生产，信任开始崩塌

今天的美妆内容里，混着 PS 拼接、局部篡改、整张 AI 生成图。它们被塞进种草帖、评论区、直播间、甚至"测评"里。三类人群受害最深：

- **青少年与容貌焦虑群体**：正处在自我认同最脆弱阶段，最容易把精修图当成"应该长成的样子"，被无效产品与医美暗示反复收割。
- **中老年与下沉市场消费者**：对"AI 图""合成图"几乎无辨别力，一条带假检测报告的"良心测评"就可能让他们买回三无产品。
- **真实创作者与诚信商家**：当假图泛滥，"谁真谁假"无从分辨，老老实实拍好物的人反而被淹没。

**信息不对称的代价从来不是平均分布的——它最重地压在辨别能力最弱的人身上。** 这正是 BeautyProof 想解决的问题：在"看图即相信"的时代，给普通人一个能追问、能取证、能说"这张图可疑"的理由。

---

## 二、回应：可解释取证，把"判断权"还给消费者

BeautyProof 面向美妆场景做 AI 图像取证。它**不替你下结论**，而是把"这张图是不是假的、哪里假、凭什么说它假"讲清楚——**降低信息不对称，而不是制造新的黑箱权威**（公益叙事 §二 + 答辩叙事与用户旅程 §一）。

它的工作方式像一次"带证据的体检"：
1. **多工具取证**：hash 指纹、c2pa 出生证、ela / trufor 篡改噪点、ocr 抄字、aigc 整图 AI 判定（团队为美妆重训的专用模型）、crossmodal 图文交叉验证——各出一份统一格式证据，可组合、可审计（答辩叙事与用户旅程 §二）。
2. **可解释 Agent 调度**：智能体决定"下一步查什么"，每条决策留人话理由，而非甩一个看不懂的分数。
3. **四档结论 + 人话报告**：`high_risk / suspicious / credible / inconclusive`，由本地大模型翻译成普通人看得懂的话（结论是什么、依据在哪、哪些我们还说不清、建议怎么办）。

**关键设计**：大模型只是"翻译官"，真正的法官是规则引擎，它绝不自己下结论。这刻意避免"机器说你假你就假"的霸权，把最终判断权交回给人——对一个公益工具，这比"准确率"更重要，因为被误伤的可能是真实的小创作者（公益叙事 §二）。

## 三、公益赋能路径：把能力开放出去，才算真的赋能

工具只是起点。我们规划四条把能力真正送到需要的人手里的路径：

1. **向消协与公益机构免费开放 API + 开源方法论**：BeautyProof 以 Apache-2.0 协议开源，检测能力以 API 形式向消费者协会、反诈中心、青少年保护类公益组织免费提供（公益叙事 §三）。一条可疑种草图，机构工作人员几秒拿到带证据的报告，用于科普辟谣或线索初筛。
2. **面向公众的科普教程**：用真实案例做成"三步看懂 AI 美妆图"的图文 / 短视频，教普通人在下单前自己先验一验——把"取证能力"变成人人可用的常识。
3. **与反诈 / 消保联动**：把"假测评、假种草、假检测报告"纳入反诈科普素材，配合监管与平台治理，从源头减少误导性内容传播。
4. **保护真实创作者**：为诚信商家与内容创作者提供"自证清白"的自检通道——一张真实图也能拿到可信报告，帮他们在"假图质疑"浪潮里守住信誉。

**赋能逻辑很朴素：我们不替公益机构做事，而是把"看清真伪"的武器递到他们手里。**

## 四、价值主张：守护"真实"，是一种社会信任基础设施

真实，是一种公共品。当一张被 AI 改写过的"完美脸"可以零成本批量生产，真实内容的信任价值就被悄悄稀释；当普通人习惯了"图可能是假的"却又无从验证，社会对"眼见为实"的信仰就会塌方——最先受伤的是年轻人的自我认知、是老人守不住的钱包、是诚实者被怀疑的委屈（公益叙事 §四）。

BeautyProof 想守护的，正是这件看起来很小、实则很大的事：**让"真实"仍然可以被验证、被相信。** 它不消灭美颜与创意，而是划出一条线——你可以修饰，但不能让人误以为"本来就这样"。这条线，就是数字时代每个人都应享有的信任基础设施。

落到可量化价值：
- **降低普通消费者被骗概率**：消费者在发布前 / 下单前多一层免费自检，把"看图即信"变成"看图可证"；创作者自检还能从源头减少坑人的假图流入（答辩叙事与用户旅程 §一 persona）。
- **给中小品牌 / 平台低成本信任基础设施**：纯 CPU 可跑、17MB 小模型（`aigc` 分类器）、Web / API 已具备，中小品牌与平台无需 GPU 机房即可部署取证能力（路演叙事 Q5 + 答辩叙事 Q7）。
- **辅助平台治理**：把检测前置到审核环节，规则引擎给出四档结论与证据，举报工单与虚假种草可由系统初筛、人工复核兜底（答辩叙事与用户旅程 §四 Q8）。
- **推动行业可信**：与 C2PA 内容溯源标准互补（我们有没有出生证都查图本身），长期推动美妆内容"可信凭证"互认（商业价值一页纸 §四）。

## 五、可信边界：我们是辅助，不是裁判（公益责任的一部分）

我们诚实声明能力边界，这本身就是公益责任：

- **它是辅助工具，不是司法鉴定**：给出的"高危 / 可疑"是风险预警，不是法律结论；涉及消费维权、平台处罚等正式场景，仍需专业机构与人工复核（README 第 412 行 + 答辩叙事 Q6）。
- **模型有已知局限**：专用模型把真实图误报压到 **1.35%**（74 张只错 1 张，`results/aigen_v2_eval.json` + 答辩叙事 Q3），但跨生成器零样本召回 `v3 0.5833 → v4 0.6667` 仍是 ImageGen 同生成器族口径（`results/crossgen_eval_v4.json`），**MJ / SD / Flux 等第三方内核尚未验证**，结论已主动标注"无法判定"区间。
- **不替代人的判断**：刻意让工具"说不清时就说不清"（弃权带实测仅 1.8%），保留人工复核入口——宁可少判，不可错伤真实创作者（答辩叙事与用户旅程 §三）。

这种克制呼应 AI 合规根本精神：**技术应当增强人的判断力，而不是剥夺它、或僭越它。** 公益的本质，恰恰是对使用者保持诚实。

---

## 六、呼应"信任守护师"赛事精神

欧莱雅「信任守护师」的命题，正是让技术成为信任的守护者而非破坏者。BeautyProof 的每一处设计都在呼应它：

- **守护普通人的判断力**——给弱者一把可握住的放大镜，而不是把判断权交给黑箱；
- **守护品牌的信任资产**——既帮品牌防冒用、也帮其 AIGC 素材自证清白（商业价值一页纸 §五）；
- **守护行业的真实底线**——用"可解释、可审计、可复核"替代"一键定罪"，让信任成为可验证的公共品。

> **结语**：BeautyProof 不生产美，也不定义美。它只想在精修图与真实皮肤之间，留一把可以被普通人握住的放大镜——让每一个被假种草图困扰的人，都能轻轻问一句"这张图，真的吗？"，然后得到一份听得懂、拿得出的答案。

> *关键事实出处：`results/aigen_v2_eval.json`（误报 66.2%→1.35%）、`results/crossgen_eval_v4.json`（跨生成器召回 0.5833→0.6667，ImageGen 同族口径）、`results/v4_eval.json`（v4 无退化）、README「数据合规红线」「合规边界」、docs/公益叙事.md、docs/答辩叙事与用户旅程.md、docs/路演叙事.md。本工具不构成司法鉴定，高风险必人工复核。*
