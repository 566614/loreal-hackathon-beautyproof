## 一、逐维度评审：得分点 vs 失分点

### 1. 创意性（商业前景）—— 预估 18/25
**得分点**：首个"美妆垂域"取证台定位（通用检测器在中文美妆域集体失效→本域微调，痛点真实）；b+c 混合架构；图文交叉验证是"别家拿不到的证据"。
**失分点**：❌ **没有商业前景一页纸**——谁付费（平台审核前置/品牌素材确权/创作者自检）、市场规模、落地路径全靠口头；评委里的投资人与业务专家（首届评审团含凯辉基金合伙人）会在此扣分。

### 2. 技术难度（代码）—— 预估 20/25
**得分点**：八工具统一证据格式工程素养高；本域微调 v1→v3 三轮实证（66.2%→1.4% 误报、跨生成器 25%→100%）；可解释 Agent 有决策日志；11 项单测；TruFor/自训模型结合。
**失分点**：❌ 算法是成熟组件组合、无方法级创新（被追问"技术难度在哪"时只有工程答案）；❌ 跨生成器 100% 只是 ImageGen 风格口径，**MJ/SD/Flux 内核未验证**——这是"技术难度"维度最大的可被攻击点；❌ 无 CI/无 benchmark 对标（没和 FSD 等前沿方法同台比过数字）。

### 3. 完成度（呈现/速度/需求匹配）—— 预估 22/25
**得分点**：真能跑的闭环（线上 Demo 200、CPU 可跑、四形态交付）；数据集闭环多版本留痕；Agent 决策可审计。
**失分点**：❌ **无成片演示视频**（"呈现方式"直接缺一块）；❌ 线上 Demo 与本地 demo 仍是 v2 时代版本，与 PPT/报告的 v3 数字**不一致**（评委实测会发现）；❌ `reports/` 18 份样例报告由旧模型生成；❌ 视频模态未接（赛题标签 #多模态，素材包里 11 个 mp4 躺着没用）；❌ OCR 34.5s/张拖慢整体速度（"运行速度"子项）。

### 4. 社会价值 —— 预估 12/15
**得分点**：保护易被"AI 种草图"误导的消费者、守护创作者信任；全部真实素材、不碰隐私红线。
**失分点**：❌ 公益/社会价值**没有成文的叙事与数据**（如"AI 美妆内容占比/受骗案例"），而单项奖里明摆着有"公益赋能奖"。

### 5. AI 合规性 —— 预估 9/10
**得分点**：Apache-2.0 + NOTICE（TruFor 等第三方声明）、仓库 public、数据红线全守住、非美妆数据刻意不用。
**失分点**：🟡 TruFor 无许可证（已声明"研究用途"，答辩需主动说）；🟡 规则第 3 条"队间不得共享代码，雷同即全队取消成绩"——需与队友自查代码来源干净。

**当前总分估计 ≈ 81/100**（主观重构口径）。

## 三、拿奖金的路径策略

1. **主目标**：冲进决赛 14 席（早鸟 5 + 常规 9）→ 决赛现场路演争一二三等奖（最高 8 万）。
2. **现实兜底**：单项奖（**技术奖**与我们匹配度最高，公益赋能奖次之）与明日之星——大概率不要求进决赛，按首届标准我们的完成度+合规在全部提交作品里属第一梯队。
3. **通道建议**：**走早鸟（10/7）**——5 个席位、早期提交池小、未入围自动流转常规（零损失）、CIIE 曝光。**代价是 10/7 版本冻结** → 所以上表优先级 1–5（约 7 小时 + 队友供图）必须在 10/6 前完成；视频模态（#6）若来不及就放弃，留到常规通道也是自动升级。
4. **数据背景**：本届 273 队报名、决赛仅 14 席（≈5%）。首届 136 份作品也是 14 支进决赛——**提交率才是第一道过滤器**（很多队交不出来），我们"真能跑的闭环"在这一关优势最大。
