# BeautyProof · 公益叙事

> 申报奖项：欧莱雅黑客松「公益赋能奖」｜对齐维度：社会价值
> 一句话：我们做的不只是一个检测工具，而是一把帮普通人拿回"判断力"的放大镜——让真实，重新成为可以被相信的事。

---

## 一、问题（Problem）：当"完美"变得廉价，信任就开始崩塌

小雅今年 17 岁，正在为脸上的几颗痘痘焦虑。她在刷短视频时，被一张"零瑕疵水光肌"的美妆种草图吸引——皮肤通透得像换了层皮，文案写着"连敷三天，烂脸也能救回来"。她攒了两周零花钱买下那套产品，收到货才意识到：图是 AI 精修过的，真实肤质、光线、甚至五官比例都被改写过。产品没用，钱白花了，而更深的伤是——她开始怀疑，自己"永远达不到"的那张脸，原来是假的。

小雅不是个例。

今天的美妆内容里，混着 PS 拼接、局部篡改、整张 AI 生成图。它们被塞进种草帖、评论区、直播间、甚至"测评"里。对三类人群伤害最深：

- **青少年与容貌焦虑群体**：正处在自我认同最脆弱的阶段，最容易把精修图当成"应该长成的样子"，被无效产品与医美暗示反复收割。
- **中老年与下沉市场消费者**：对"AI 图""合成图"几乎没有辨别力，一条带假检测报告的"良心测评"就可能让他们买回三无产品。
- **真实创作者与诚信商家**：当假图泛滥，"谁真谁假"变得无从分辨，老老实实拍好物的人反而被淹没。

信息不对称的代价，从来不是平均分布的——它最重地压在辨别能力最弱的人身上。这就是 BeautyProof 想解决的问题：**在"看图即相信"的时代，给普通人一个能追问、能取证、能说"这张图可疑"的理由。**

---

## 二、我们的回应（Response）：可解释取证，把"判断权"还给消费者

BeautyProof 是一个面向美妆场景的 AI 图像取证工具。它不替你下结论，而是把"这张图是不是假的、哪里假、凭什么说它假"讲清楚——这正是公益价值的核心：**降低信息不对称，而不是制造新的黑箱权威。**

它的工作方式像一次"带证据的体检"：

1. **多工具取证**：查图片指纹（hash）、查出生证（C2PA 元数据）、查篡改噪点（ELA / TruFor）、抄图上的字（OCR）、判断是不是整张 AI 生成（我们为美妆重训的专用模型）、做图文交叉验证（文案和图对不对得上）。八件工具各自出一份证据，用同一套格式，可组合、可审计。
2. **可解释 Agent 调度**：一个会"自己决定下一步查什么"的智能体，每条决策都留下人话理由，而不是甩一个看不懂的分数。
3. **四档结论 + 人话报告**：规则引擎给出「高危 / 可疑 / 可信 / 无法判定」四档；最后由大模型把结论翻译成普通人看得懂的话——结论是什么、依据在哪、哪些我们还说不清、建议怎么做。

关键设计：**大模型只是"翻译官"，真正的法官是规则引擎，它绝不自己下结论。** 这意味着我们刻意避免"机器说你假你就假"的霸权，把最终判断权交回给人。对一个公益工具而言，这比"准确率"更重要——因为被误伤的，可能是一个真实的小创作者。

## 三、公益赋能路径（Empowerment）：把能力开放出去，才算真的赋能

工具本身只是起点。我们规划了四条把能力真正送到需要的人手里的路径：

1. **向消协与公益机构免费开放 API + 开源方法论**：BeautyProof 以 Apache-2.0 协议开源，检测能力以 API 形式向消费者协会、反诈中心、青少年保护类公益组织免费提供。一条可疑种草图，机构工作人员几秒就能拿到带证据的报告，用于科普辟谣或线索初筛。
2. **面向公众的科普教程**：用真实案例做成"三步看懂 AI 美妆图"的图文 / 短视频教程，教普通人在下单前自己先验一验——把"取证能力"变成人人可用的常识。
3. **与反诈 / 消保联动**：把"假测评、假种草、假检测报告"纳入反诈科普素材，配合监管与平台治理，从源头减少误导性内容的传播。
4. **保护真实创作者**：为诚信商家与内容创作者提供"自证清白"的自检通道——一张真实精修图也能拿到可信报告，帮他们在"假图质疑"浪潮里守住信誉。

赋能的逻辑很朴素：**我们不替公益机构做事，而是把"看清真伪"的武器递到他们手里。**

---

## 四、价值主张（Value）：守护"真实"，是一种社会信任基础设施

商业世界里，BeautyProof 可以是平台的审核前置、品牌的确权工具、创作者的自检器。

但我们认为，它更大的意义在商业之外——

**真实，是一种公共品。** 当一张被 AI 改写过的"完美脸"可以零成本批量生产，真实内容的信任价值就被悄悄稀释；当普通人习惯了"图可能是假的"却又无从验证，整个社会对"眼见为实"的信仰就会塌方。这种塌方，最先伤害的是年轻人看待自己的方式，是老人守不住的钱包，是诚实者被怀疑的委屈。

BeautyProof 想守护的，正是这件看起来很小、实则很大的事：**让"真实"仍然可以被验证、被相信。** 它不是要消灭美颜与创意，而是划出一条线——你可以修饰，但不能让人误以为"本来就这样"。这条线，就是数字时代每个人都应享有的信任基础设施。

---

## 五、可信边界（Honest Boundary）：我们是辅助，不是裁判

我们诚实地声明 BeautyProof 的能力边界，这本身就是公益责任的一部分：

- **它是辅助工具，不是司法鉴定**。它给出的"高危 / 可疑"是风险预警，不是法律结论；涉及消费维权、平台处罚等正式场景，仍需专业机构与人工复核。
- **模型有已知局限**。我们的专用模型在美妆域内把真实图误报压到了 1.4%，但对 Midjourney / Stable Diffusion / Flux 等第三方生成器的泛化仍需持续校准，结论中已主动标注"无法判定"的区间。
- **不替代人的判断**。我们刻意让工具"说不清时就说不清"，并保留人工复核入口——宁可少判，不可错伤真实创作者。

这种克制，呼应了 AI 合规的根本精神：**技术应当增强人的判断力，而不是剥夺它、或僭越它。** 公益的本质，恰恰是对使用者保持诚实。

---

> **结语**：BeautyProof 不生产美，也不定义美。它只想在做梦一般的精修图与真实的皮肤之间，留一把可以被普通人握住的放大镜——让每一个小雅、每一位被假测评困扰的长辈，都能轻轻问一句："这张图，真的吗？"然后，得到一份听得懂、拿得出的答案。
