## 1. 两种情况的对比（先讲清区别）

赛题要求"原创性 + 数据来源合规"。把模型来源拆成两类，对原创性的影响完全不同：

| 维度 | 情况一：使用他人预训练**来源模型** | 情况二：使用他人**成千上万张图片的训练库** |
| - | - | - |
| 是什么 | 拿别人已训好的模型权重（如 ImageNet/MobileNetV3）当骨干 / 初始化，再**自己微调** | 直接拿别人标注好的大规模数据集（GenImage、ImageNet 标签、COCO 等）去**训练自己的模型** |
| 是否常见 | ✅ 业界标准做法（迁移学习），天池规则未禁止 | ⚠️ 可用但风险高 |
| 合规要点 | 只需**声明来源 + 许可证**，不据为己有即可 | ① 数据授权/版权/隐私红线；② 若"创新"仅仅是"用大数据训了个模型"，易踩规则第 3 条"**没有实际创新贡献**"被淘汰 |
| 对原创性的影响 | **不削弱**——创新在"微调 + 上游工程 + 场景适配" | **削弱**——模型能力主要来自数据，而非你的贡献 |
| 本作品属于 | ✅ **这一类** | ❌ **不属于** |

**关键区分点**：预训练骨干权重是"模型能力的起点"，我们用它做初始化后，**在自己生产的 ~135 张美妆图上完成了领域微调**；我们并没有把任何第三方大规模图库当作训练集灌进去。ImageNet 的 128 万张图只是"训出那个骨干的人用过的数据"，不是"我们训练 AIGC 模型用的数据"。

## 2. 本作品 AIGC 模型的来源判定（证据）

本作品的核心自训模型：`models/beautyproof_aigen_v1 / v2 / v3`（当前线上 `MODEL_PRIORITY` 首位 = **v3**）。

### 2.1 用了他人的预训练来源模型（情况一）✅

| 项 | 内容 | 证据 |
| - | - | - |
| 骨干（backbone） | **`timm/mobilenetv3_large_100.ra_in1k`**（timm 发布的 ImageNet-1k 预训练 MobileNetV3-Large 权重） | `tools/train_aigen_v2.py` / `train_aigen_v3.py` 的 `BACKBONE_REPO` 常量；`models/beautyproof_aigen_v3/config.json` 的 `"arch": "mobilenetv3_large_100"` |
| 使用方式 | **仅作初始化权重**：`timm.create_model(pretrained=False)` + 手动 `load_state_dict` 灌入骨干张量，分类头丢弃重训 | `make_model()` 函数（`strict=False`，只加载形状匹配的骨干张量） |
| 许可证 | MIT / Apache-2.0（timm 库） | `NOTICE` 第 3 条、`SOURCES.md` §1.5 |
| 是否据为己有 | 否。权重由团队从官方 Hub 取得，不主张其知识产权 | `NOTICE` 第 9 条 |

→ **这是情况一，已声明、已合规。**

### 2.2 没有使用他人的训练库（情况二）❌

| 项 | 内容 | 证据 |
| - | - | - |
| 训练数据总量 | **约 135 张**（非"成千上万"）：即梦 AI 20 + 跨生成器 ai_cross 26 + 真实精修美妆 real_xhs 74 + 原有 real/clean/tampered 约 15 | `train_aigen_v3.py` 的 `build_pairs()` 与日志输出 |
| 数据来源 | **全部团队自产**：即梦（ImageGen）文生图 + 用户/队友提供的真实精修美妆图 + 自产跨生成器图（ai_cross）。**未抓取任何第三方平台图** | `data/REAL_AI_DATASET.md`、`SOURCES.md` §1.7 |
| 是否用了 GenImage / ImageNet / COCO 等第三方大规模标注集做训练 | **否**。GenImage 仅作离线评测参考，**不入仓、不进训练** | `SOURCES.md` §1.7、模型训练脚本只读取 `data/` 下自产子目录 |
| 数据红线 | 遵守版权 / 隐私 / 非商用 / 主题不冒用（小红书图只落 `outputs/` 不入库） | `docs/赛题驱动_模型清单与MediaCrawler数据利用.md` 第五节 |

→ **我们不属于情况二。我们的训练能力来自"自建的小规模美妆域数据 + 领域微调"，这正是赛题要的原创贡献。**

## 5. 诚实边界（答辩必主动说，不藏着）

1. **跨生成器泛化**：v3 在 `data/ai_cross` 的 held-out 召回 100%（v2 仅 25%），但**ai_cross 仍是 ImageGen 风格自产图**，未覆盖 MJ/SD/Flux 真·第三方生成器。若评委要求"换生成器还灵吗"，需如实说明并提供 v3 训练脚本与方案（`docs/跨生成器验证方案.md`）证明方法可复现。
2. **骨干来源是公开的**：ImageNet-1k 预训练权重本身是公开资源，我们用它初始化再微调，这是标准做法，不影响原创性判定。
3. **数据集规模小**：受控集约 135 张，统计说服力有限——但全部为真实美妆域样本，且我们主动暴露了边界（见 `data/REAL_AI_DATASET.md` 第 5 节）。

## 6. 机器可核验来源（provenance 落点）

为让来源声明可被评审直接核验，训练脚本在生成 `model.pt` 时一并写出 `config.json`，其中记录：

- `"framework": "timm"`、`"arch": "mobilenetv3_large_100"`（骨干架构）
- `"trained_on"`：本次训练用的自产数据清单与张数
- **`"backbone_source"`**：`timm/mobilenetv3_large_100.ra_in1k`（ImageNet-1k 预训练权重，仅初始化，MIT/Apache-2.0）

详见 `models/beautyproof_aigen_v3/config.json`。
