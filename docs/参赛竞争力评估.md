# 参赛竞争力评估（赛题2「信任守护师」· L'Oréal Brandstorm / 天池 532496）

> 评估基于项目实际状态（六工具流水线 + 本域微调 AIGC v3 + TruFor 篡改定位 + 规则引擎 +
> 合规数据治理 + 已上线 demo/视频/CI），不美化、不藏短。概率为主观校准，非保证。

---

## 一、获奖可能性

### 评委看什么（赛题2 内核 = 「信任守护师」）
1. **原创性 / 不侵权**：方案与数据来源合法合规。
2. **创新贡献**：不是简单套开源，要有自己的适配与系统级设计。
3. **可行 & 可用**：真能跑、有 demo、有可解释输出。
4. **业务价值**：解决「美妆内容信任」的真实痛点，有清晰用户场景。
5. **表达**：答辩叙事能把技术短板讲成取舍与严谨。

### 概率校准（中国区赛事，强队多）
| 档位 | 概率（主观） | 条件 |
|------|------|------|
| 入围决赛 / 拿任意奖项 | **中高 50–65%** | demo 稳、合规硬、叙事清楚 |
| 前三 / 一等奖 | **中等偏低 20–35%** | 需在「真实鲁棒性 + 业务叙事」上明显压过对手 |
| 总冠军 | **低 10–20%** | 依赖对手失误 + 我们短板补齐 |

**关键不确定项**：评委很可能拿**自己的图**现场测（重度滤镜真实美妆照、MJ/SD/Flux 原生图）。
我们的软肋正好在这两块——若现场翻车，概率骤降；若提前把这两块讲成「已知边界 + 人工复核兜底」，
反而显严谨、不掉分。

## 二、当前水平 + 优势 / 不足

### 水平定位
**完成度高的可用原型（MVP→接近 demo-ready），不是生产系统**。技术链完整、能跑、有合规护城河，
但数据规模与真实鲁棒性是硬伤。

### 优势（答辩可打的点）
1. **真·多工具融合流水线**：hash/c2pa/ela/ocr/aigc/trufor + 图文交叉 → 规则引擎四档 → 取证报告。
   不是单模型，而是「取证工作流」，契合「信任守护」的系统级命题。
2. **本域微调 AIGC 模型**：v3 val_acc 0.963、跨生成器 held-out 召回 100%；通用鉴伪模型（AIRealNet/capcheck）
   在中文美妆域失效，我们踩过坑后自训，这是真实差异化。
3. **合规护城河（铁壁）**：全程自产数据，拒绝 GenImage（CC BY-NC-SA 非商用）/COCO/品牌图，骨干来源
   ImageNet-1k 权重**仅初始化且机器可核验披露**。在 20 万奖金商业场景下，这比「直接拿来用」成熟得多，
   是评委眼里的加分项，不是负担。
4. **可解释 + 弃权带**：TruFor 热力图 + 文案体检 + 图文交叉 + [0.5,0.6) 模糊带交人工复核，human-in-loop，
   正好命中赛题「信任」内核（可审计、不黑盒定罪）。
5. **工程完成度**：已上线 web demo + 离线版 + 演示视频 mp4 + GitHub Actions CI 绿 + 11 项单测通过。
6. **诚实边界意识**：主动区分「受控集 100%」与「真实集 66% 误报」，对外只报真实集——评委最烦虚高，
   这种严谨反显专业。

### 不足（必须正视）
1. **真实分布覆盖薄**：训练真实图仅 ~84 张（real_xhs 74 + real 10），且多为「精修美妆照」。
   重度滤镜/磨皮的真实照仍可能误报——这是答辩最该补的短板（v2 已把 66%→1.4%，但验证集未参与训练）。
2. **跨生成器未真验证**：ai_cross 是 ImageGen 风格，**不等于真实 MJ/SD/Flux 原生图**；换生成器召回未必稳。
3. **数据规模百张级**：模型概率已饱和到 0/1，泛化上限受限于小数据，不能说「很准」。
4. **业务叙事偏弱**：目前偏「技术 demo」，缺清晰 persona（消费者扫码验真？品牌方监测？平台审核？）
   与端到端用户旅程，Brandstorm 看重商业思维。
5. **「像组装开源」风险**：TruFor + 分类器本质是成熟组件，若叙事只讲「我接了这些工具」，原创性会被质疑。
   必须讲成「领域适配 + 规则引擎 + 治理 + 可解释报告」的系统创新。
6. **非司法鉴定**：分数非法律结论，高风险必人工复核——这是边界，不是卖点，需在答辩里自然带过而非硬撑。

## 三、提升竞争力与获奖概率的具体优化方向（按 ROI 排序）

### ① 彻底补真实分布覆盖（最高 ROI，已在做，加速推进）
- 走 `docs/自产实拍采集指南.md`：老板/队友拍自己拥有的欧莱雅产品（原图不修图、留 EXIF）→
  `data/xhs_real_unlabeled/` → `pseudo_label.py` 伪标注 → `train_aigen_v4.py`。
- 这是把「真实美妆照误报」从根上压下去的唯一可靠路，也是「未修图原始参考图」的合规来源。
- **验收**：真实集误报率重新测，目标 ≤5%；若达不到，至少在答辩把「已知边界+人工复核」讲透。

### ② 跨生成器零样本验证（答辩必被问，低成本补）
- 向老板要 MJ / SD / Flux 各 2–3 张真·原生美妆图，做 `ai_cross` 原生补充，测跨生成器召回。
- 若拿不到：把叙事锚定在 **TruFor（生成器无关）作鲁棒主干**，AIGC 整图判定仅作辅助——
  把短板变成「架构取舍」的加分讲述。

### ③ 把「合规 + 可解释」讲成核心卖点（零成本、最高杠杆的叙事升级）
- 主线叙事：**「可审计的美妆内容信任层」**——六工具交叉取证 + 机器可核验来源披露 + 人类复核兜底。
- 对比「黑盒 AI 一键判真假」：我们强调「不替你定罪，只给你可解释证据 + 风险提示」，直接对应赛题「信任守护师」。
- 把拒绝 GenImage/品牌图讲成「在商业赛事里主动守合规红线」，显成熟。

### ④ 定义清晰用户场景与端到端旅程（补商业思维短板）
- 选 **1 个**最强 persona（建议：消费者/达人「上传美妆图 → 秒出取证报告 → 是否疑似 AI/篡改/违规宣称」），
  做一条完整 demo 动线，而非只亮分数。Brandstorm 评商业落地，旅程比模型精度更抓人。
- 可加轻量「品牌方监测」视角作为延伸，但不要散。

### ⑤ 评测透明度页（反显严谨，防现场翻车）
- 准备一页「自评边界」：受控集 vs 真实集准确率分列、跨生成器状态、已知盲区 + 应对。
- 评委现场拿图测时，主动说「这类我们已标注为需人工复核」比被问住更稳。

### ⑥ 工程与体验打磨（保底分）
- demo 稳定性（线上 https://beautyproof-demo.app.workbuddy.host/ 持续可访问）、报告可读性、
  移动端/扫码场景若赛题鼓励可加；CI/单测保持绿。

### ⑦ 轻量 RL / 阈值自动调优（可选，非当前重点）
- 数据扩到千张级后，可做「弃权阈值 + 增强强度」的轻量 RL 调参层（只用自有数据）。当前百张级不必，
  别为「显得用了 RL」而硬上——评委更认「对症的解法」。

---

## 四、一句话结论
**技术完成度与合规护城河是我们的强项，真实鲁棒性与业务叙事是短板。** 把 ①②③ 做成（自产实拍压误报 +
跨生成器验证 + 合规可解释叙事），拿奖概率从中等拉到中高；不补则容易在「现场真图测试 + 商业叙事」上被更强队反超。
优先级：**自产实拍扩充 > 跨生成器验证 > 叙事升级 > 用户场景 > 评测透明页**。
（注：CC 图库采集仅作合规补充参考，对降误报帮助有限，非主线。）
