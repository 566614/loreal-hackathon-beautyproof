# BeautyProof 演示视频脚本（2–3 分钟）

> 配套走查页：`demo/video_walkthrough.html`（自动播放 + 可录屏）。
> 用法：用 OBS / 系统录屏打开该 HTML，全屏录制自动播放过程即可；下方为同步旁白。总时长约 2 分 30 秒。

| 时间 | 场景 | 画面 | 旁白（口播） |
| - | - | - | - |
| 0:00–0:20 | 封面 | 标题「美妆图，经得起追问吗？」+ 四个标签 | 大家好，我们是 BeautyProof。今天的美妆种草图里，混着 PS 拼接、局部篡改、还有整张 AI 画的图。普通人根本分不清。我们的目标很简单——让每一张美妆图，都经得起追问。 |
| 0:20–0:35 | 输入 | 一张口红试色图落入 | 把一张口红试色图丢进来。它可能是种草帖、评论区、或品牌素材。我们事先并不知道它是拍的还是 AI 画的——BeautyProof 要做的，就是给它一份带证据的体检报告。 |
| 0:35–1:05 | 取证 | 八工具逐个打勾 | 进来之后，八件工具各自出一份证据：查图片指纹、查出生证、查篡改噪点、抄图上的字、判断是不是整张 AI 生成的——我们用的是自己为美妆重训的模型；再查局部篡改定位、分析文案、做图文交叉验证。所有证据用同一套格式，可组合、可审计。 |
| 1:05–1:30 | 判定 | 规则引擎四档 | 可解释 Agent 会决定下一步查什么，规则引擎给出四档结论：高危、可疑、可信、或无法判定。这张图，被判为「高危——高度疑似 AI 生成」。 |
| 1:30–1:55 | 报告 | 四段式人话报告 | 最后，大模型把结论翻成普通人看得懂的话：结论是什么、依据在哪、哪些我们还说不清、建议怎么做。注意，大模型只是翻译官，真正的法官是规则引擎——它绝不自己下结论。 |
| 1:55–2:20 | 翻车→修复 | 66.2% → 1.4% 动态条形图 | 这里是我们最想讲的一个真实翻车。一开始用通用检测模型，真实精修美妆图被误判成 AI 的比例高达 66%。我们没有硬撑，而是用 74 张真实图加 20 张即梦图，为美妆重训了一版模型。误报直接从 66% 压到 1.4%，AI 召回保持 100%。 |
| 2:20–2:35 | 结尾 | CTA + Demo 链接 | 这就是 BeautyProof：TruFor 篡改定位加图文交叉验证是我们的主防线，整图 AI 判定我们主动说「校准中、高风险人工复核」。欢迎评委实测我们的在线 Demo。谢谢。 |

## 录制小贴士
- 全屏 1080p，录 `demo/video_walkthrough.html` 自动播放一轮（约 36 秒一轮，可录 1–2 轮或按场景手动暂停讲）。
- 若想更稳，可在「取证」「翻车修复」两屏手动暂停，配上方口播，总控 2–3 分钟。
- 旁白可换成团队真人配音；文案已按 5+5 评审的 INNOVATIVE / FEASIBLE / RESILIENCE / LEARNING AGILITY 埋点。
