# BeautyProof · 商业价值一页纸

> 赛题 2「信任守护师」｜ 美妆图篡改 / AI 生成取证工具
> 用途：决赛答辩「创意性 / 商业前景」维度（估权重 ~25%，设「商业价值奖」单项奖）+ PPT 同步
> 一句话定位：**把"鉴伪"做成"可解释取证"，把"分数"做成"可审计、可上会、可行动的信任证据链"。**
> 口径红线：本工具**不声称司法鉴定 / 法律结论**，分数仅为风险参考，高风险必人工复核（见 README 合规边界）。

## 一、痛点（赛题 2 · 为什么这事值得做）

美妆是 AI 伪造与局部篡改的**重灾区**——种草图、试色图、评论区、直播间、测评里混着 PS 拼接、局部篡改、整张 AI 生成图。它同时压垮三方：

| 受害方 | 痛点 | 现状代价 |
|---|---|---|
| **消费者** | 看不出真假的"完美脸"诱导下单 → 花冤枉钱、对品牌失望 | 信息不对称代价压在辨别力最弱的人身上 |
| **品牌方** | 信任资产被虚假种草 / 仿冒素材悄悄侵蚀；自家 AI 素材也需"自证清白" | 欧莱雅连续居中国美妆市占率第一（~14.5%，Euromonitor），信任是其核心资产 |
| **平台 / 监管** | 虚假种草、假测评治理难，内容审核靠人肉、投诉才处理 | 海量 KOL 图文 / 短视频即鉴伪对象，治理成本高、滞后 |

**更扎心的行业事实**：现成的通用 AI 检测模型在中文美妆域**集体失效**——真实精修美妆图被误判为 AI 的比例高达 **66.2%**（`results/aigen_v2_eval.json`），AIRealNet 基本判反、capcheck 把真实图全判 human（答辩叙事与用户旅程 Q4）。现成方案失灵，恰是 BeautyProof 的差异化空间。

---

## 二、解决方案（六工具取证 + 规则引擎 + 可解释报告）

BeautyProof 给美妆**单独做了一台"内容体检中心"**，把黑盒打分升级为证据链：

1. **多工具交叉取证（统一证据格式 `{tool, observed, cannot_prove, evidence[]}`）**
   - `hash` 图片指纹（命中品牌原图库即确权）
   - `c2pa` 内容凭证（查来源 / 编辑史"出生证"）
   - `ela` 压缩痕迹、`trufor` 篡改定位（CVPR 2023，标出被 P 过的局部热力图）
   - `ocr` 文字识别、`text` 文案合规体检（违禁宣称逐条给法律出处）
   - `aigc` 整图 AI 生成检测（**团队为美妆本域微调的 17MB 小模型**）
   - `crossmodal` 图文交叉验证（"原相机实拍"却被判 AI 生成 = 最硬证据）
2. **规则引擎四档定级**：`high_risk / suspicious / credible / inconclusive`，每条理由可回溯，**分数不暗箱**（答辩叙事与用户旅程 §二）。
3. **可解释报告（human-in-the-loop）**：LLM 只做"翻译官"把结论译成大白话，**法官永远是规则引擎**；高风险一律出口人工复核，弃权带（实测仅 1.8%）主动说"拿不准"（答辩叙事与用户旅程 §三）。

**核心壁垒不在"某个模型更准"，而在"证据可审计、可追溯、可上法庭前置筛查"**——这是黑盒竞品给不了、B 端 / G 端付费意愿最高的部分。

## 四、商业前景与差异化（为什么我们能成）

**市场规模（诚实区间，均引第三方公开口径）**
- TAM：中国 AIGC 检测 / 深伪检测市场 2025 约 **43.8 亿元**，2026 预计 **63.4 亿元**（中国信通院 + 工信部，雪球 2026 转引）；广义 AIGC 内容检测 2025 ~45 亿元。
- SAM：2025 中国化妆品全渠道交易额 **1.10 万亿元**，线上占 **65.36%（≈7218 亿元）**；按内容安全 + 打假 + 合规审核支出占营销额 0.1%–0.3% 估算，美妆垂域 ≈ **22 亿元 / 年**（中国香妆协会）。
- SOM：以欧莱雅为锚点 API / 订阅切入，3 年内取垂域 **5%–10%** → ≈ **1–2 亿元 / 年**。
- 来源：中国香妆协会《2025 中国化妆品产业数据发布会》、Euromonitor、中国信通院 + 工信部深伪检测数据（商业前景.md 数据来源段）。

**三大差异化（技术即护城河）**
1. **生成器无关的鲁棒主干**：TruFor 篡改定位查"图被局部动过"，与任何生成器无关；图文交叉验证也不依赖生成器特征——这两道是生成器无关防线（`results/crossgen_eval_v4.json` 结论段）。
2. **本域微调 AIGC 分类器**：MobileNetV3，用团队自产美妆图微调，误报 **66.2% → 1.35%**、AI 召回 100%（`results/aigen_v2_eval.json` + 答辩叙事 Q3）；17MB 纯 CPU 可跑，低成本部署。
3. **合规自产数据（护城河也是红线）**：训练数据约 **135 张全部团队自产**（即梦 / ImageGen 平台自产 AI 图 + 团队实拍 + 现场合成），**绝不引入 GenImage / COCO / ImageNet 作训练集**（ImageNet 仅作骨干初始化权重，机器可核验）；骨干来源写进模型 `config.json`（README「数据合规红线」+ 答辩叙事 Q5）。

**落地路径（轻量、可规模化）**
- 短期（0–6 月）：品牌内审插件 / 私有化 API（已具备 Flask 取证台、线上 Demo）。
- 中期（6–18 月）：平台美妆内容审核接入，补齐跨生成器真图校准。
- 长期（18–36 月）：推动美妆内容"可信凭证"，对齐 C2PA / 内容溯源标准，成为行业信任基础设施。

**商业模式**：① API 按调用量计费（平台 / MCN）；② 企业版订阅（品牌内审平台 / 私有化）；③ 带完整证据链的 PDF 鉴定报告服务（维权机构 / 监管 / 司法前置筛查）。

## 五、与欧莱雅战略契合点

- **守护信任资产**：防御"AI 种草图 / 虚假测评"对市占率第一品牌的信任侵蚀。
- **既是防守盾，也是自检镜**：欧莱雅自身大量使用 AIGC 营销，也需自证清白的工具。
- **可解释 = 可合规**：四档结论 + 证据链天然满足广告法 / 化妆品监管"可举证、可追责"要求（README 合规边界）。
