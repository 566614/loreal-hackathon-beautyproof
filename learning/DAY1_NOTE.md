# Day 1 学习笔记：Python 三个最基础的概念

> 你（阮）是后端组 + 工具组，全部代码最终由你写。今天只学「能跑起来」的最小一块。

## 1. 变量（variable）—— 给东西起名字

```python
image_name = "001_real_lipstick.jpg"
score = 0.87
```

- 等号 `=` 是「把右边的值，存到左边的名字里」，不是数学里的相等。
- 文字要加引号 `"..."`，数字不用。
- 后面想用这个值，直接写名字就行：`print(image_name)`。

**生活比喻**：便利贴。你在盒子上写「口红图」，下次找直接看便利贴，不用打开盒子确认。

## 2. 函数（function）—— 把动作打包，取个名

```python
def greet(who):
    print("你好，" + who + "！")
```

- `def` 是「定义一个函数」。
- `who` 是参数：调用时从外面传进来的值。
- 函数体要**缩进**（前面空 4 个空格），Python 靠缩进判断「哪几行属于这个函数」。

**生活比喻**：微波炉的「热牛奶」快捷键。你不用每次设时间火力，按一下就行。

## 3. 读文件（read file）—— 让助手把文件内容读出来

```python
with open("data/SCHEMA.md", "r", encoding="utf-8") as f:
    content = f.read()
```

- `open(路径, "r")` = 以「读(r)」模式打开文件。
- `encoding="utf-8"` = 告诉助手「这是中文文件，按中文解码」，不加这行中文会乱码。
- `with ... as f` 是固定写法，意思是「打开文件，用完自动关」，你先照抄，后面会懂。

**生活比喻**：让助手翻开登记表，把上面写的内容念给你听。
